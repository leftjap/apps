# taste — 디자인 작업지시서 (Claude Design 입력용)

> 이 문서는 Anthropic **Claude Design**(claude.ai 사이드바 → 팔레트)에 입력해 taste 앱 UI 시안(실행가능 HTML/CSS/JS)을 생성하기 위한 작업지시서다.
> 기능·데이터 설계는 `taste-app-spec.md`, 구현 플랜은 `taste-wave1-plan.md` 참조.
> **확정 방향:** 데스크톱 주력 + 모바일 대응(반응형), 4앱 디자인 언어 충실(절제).

## 1. 디자인 시스템 (★ Claude Design에 첨부할 것)

**Claude Design 온보딩 시 이 파일들을 첨부**해 디자인 시스템을 흡수시킨다:
- `~/apps/DESIGN.md` — 4앱 공통 토큰·원칙 SSOT
- `~/apps/book/src/styles/book.css` — Pretendard 계열 실제 토큰(데스크톱 독서형, taste와 가장 가까움)
- `~/apps/study/src/styles/session.css` — **ScorePill**(별점 배지 차용 원본)

흡수 안 될 경우를 대비한 **핵심 토큰 요약**. ★ 모든 값 직접 Read로 검증 — 줄마다 출처 표기:

```css
/* 색·잉크·액센트·폰트 — 출처: book/src/styles/book.css:5-11 (직접 확인) */
--bg:#ffffff; --paper:#f6f4ee; --paper-2:#efece4;
--line:#ececea; --hover:#f4f2ec;
--ink-1:#15140f; --ink-2:#4a473f; --ink-3:#8a877d; --ink-4:#b8b5aa;
--warm-soft:#d97757;  /* = 코랄(Crail) 액센트. 화면당 1~2회, 점 단위만 */
--warm:#c2553a;       /* 액센트 deep */
/* 폰트 (book.css:9-11) — 데스크톱 주력이라 book 계열. study/gym 의 Poppins+Noto Sans KR 은 모바일 계열이라 미사용 */
--sans:"Pretendard"; --serif:"Noto Serif KR"; --mono:"JetBrains Mono";

/* 점수색 — 출처: study/src/styles/tokens.css:24-26 (직접 확인) */
--gold:#c4973b;   /* (= study --amber) 별점 채움 */
--sage:#788c5d;   /* 긍정/추천 */
--danger:#b44d3b; /* 비추 강조·삭제 */

/* 그림자·간격·radius — 출처: DESIGN.md:105-108,129-139 (직접 확인).
   ※ 이 그림자는 DESIGN.md 정본이며, book 은 같은 사상을 --sh-pop 1개로 단축함 */
--shadow-float: 0 1px 0 rgba(20,18,14,.02), 0 6px 14px -8px rgba(20,18,14,.08), 0 24px 48px -24px rgba(20,18,14,.18);
--shadow-pop:   0 1px 0 rgba(20,18,14,.03), 0 8px 16px -10px rgba(20,18,14,.18), 0 24px 48px -24px rgba(20,18,14,.24);
--shadow-inset-soft: 0 4px 12px -8px rgba(20,18,14,.08);
--sp-1..8: 4/8/12/16/24/32/48/64;   --r-sm:8 --r-md:12 --r-lg:18 --r-xl:24;   /* 칩·pill = 999px */
```

- **타이포:** 본문 `Pretendard`(book `.bk` = **15px**, 자간 -.012em, `word-break:keep-all`, `text-wrap:pretty`). 강조 인용·추천 이유만 `Noto Serif KR`. 숫자·날짜·별점값은 `JetBrains Mono`+`tabular-nums`(book `.mono`). [출처 book.css:40-46 직접 확인. ※ 본문 line-height 는 직접 미확인 — DESIGN.md 의 body 1.85 적용]
- **무드 규칙(DESIGN.md §5-6, 직접 확인):** 그라디언트 배경 금지, 신규 hex 금지, 액센트는 점 단위(큰 면 채움 금지), 카드 좌측 컬러보더 금지, 위계는 색이 아니라 타이포(size/weight/color)와 여백으로.

## 2. 화면별 사양

**2.1 추천(홈) `#/` — 앱의 얼굴**
- 상단: 페이지 타이틀 "추천" + 필터 칩(전체 / 영화 / 책, 999px pill, 활성 = accent-soft 배경 + ink-1 텍스트).
- 본문: 추천 **카드 그리드**. 데스크톱 `repeat(auto-fit, minmax(280px, 1fr))` gap 24 [DESIGN.md:114 정본 큰-카드 그리드, 직접 확인]. 페이지 컨테이너 `max-width:1240`(book `.bk .page` 기준 — Explore 인용, 직접 미확인 / DESIGN.md 읽기칼럼 720 은 텍스트용이라 포스터 그리드엔 더 넓게). 모바일 단일 컬럼.
- **추천 카드**(핵심 컴포넌트, §3): 포스터/표지(좌) + 제목·연도·감독/저자(메타) + **추천 이유**(serif, 2~3줄, 이게 카드의 주인공) + 하단 "왓챠에서 보기"/"알라딘에서 보기" 텍스트 링크(accent). 영화↔책 교차 추천은 작은 라벨("당신이 5.0 준 «기생충»에서 출발").
- 빈 상태: "아직 추천이 없어요. 별점을 매기면 일요일마다 새 추천이 도착합니다." + `#/ratings` 유도 버튼.
- 섹션 분리는 "에디토리얼 믹스"(book v4 사상): 큰 카드 그리드 한 덩어리 + 그 아래 얇은 구분선으로 "영화" / "책" 소제목(mono upper 라벨).

**2.2 내 평점 `#/ratings`**
- 상단 세그먼트 토글: [영화] [책] (그림자 변화로 active 시그널, 라운드 7px 그룹).
- **책 탭:** 알라딘 검색 인풋(상단 sticky, line 보더 + inset shadow, focus 시 accent 2px ring) → 결과 리스트(표지 썸네일 44px + 제목·저자, hover 배경만). 행 클릭 → 별점 입력(인라인 패널 또는 모달): 큰 표지 + 별점 위젯 + 앵커 라벨. 그 아래 이미 매긴 책 목록(`book-row` 패턴: `44px 1fr auto` 그리드, 우측에 별점·삭제).
- **영화 탭:** 왓챠 import 목록. 포스터 썸네일(있으면) + 제목·연도 + 별점 위젯(수정 가능) + 삭제. 정렬 최신순/별점순.
- 행 구분은 카드 아님 — 얇은 구분선(`border-top: 1px var(--line-soft)`) + hover 배경.

**2.3 가져오기 `#/import`**
- 안내: "왓챠피디아 평가를 CSV로 내보내 올려주세요" + 짧은 3스텝 가이드(① 왓챠 전체공개 ② 내보내기 스크립트 ③ 여기 업로드).
- 드롭존(점선 보더 r-md, 파일 선택 버튼) → 파싱 미리보기(표: 제목·연도·별점, 상단에 "영화 N건 인식, TV는 제외됨") → "저장" 버튼(진행률 바).
- 결과 토스트: "영화 N건 저장됨".

**2.4 로그인 `#/login`**
- 중앙 카드(`max-width:360`, r-lg, shadow-float): 브랜드 `taste`(소문자, 절제된 워드마크) + 한 줄 설명 + Google "G" 버튼(흰 배경 + line, 호버 lift). today 로그인 카드 패턴.

## 3. 컴포넌트 인벤토리

| 컴포넌트 | 사양 |
|---|---|
| **별점 위젯**(신규 핵심) | 별 5개, 각 별 좌/우 절반 클릭 = **0.5 단위**(0.5~5.0). 채움색 `--gold`. 우측에 **앵커 라벨**: ★0.5=**비추**(danger 톤), ★1~2=별로, ★2.5~3=보통, ★3.5~4=추천, ★4.5~5=최애. 반쪽 별은 star-fill을 width:50% 클립으로 합성(book `icons.js`의 star/star-fill 재사용). 읽기전용 변형(목록용)도. |
| **추천 카드** | 흰 배경 + line + r-md. 포스터/표지(§ cover) + 메타(제목 16/600, 연도·감독 mono meta 12) + 이유(serif 14~15, 2~3줄 clamp) + 액션 링크. hover 시 살짝 lift. 좌측 컬러보더 금지. |
| **포스터/표지**(cover) | book `cover.js` 사상: 실제 판형비(영화 2:3, 책 b.w/b.h)로 높이 산출(그리드 단조 방지). `coverUrl` 있으면 `<img cover>` + 대각 글로스 `linear-gradient(150deg, rgba(255,255,255,.05), rgba(0,0,0,.10))` + 우측 1px 스파인 + 3겹 웜블랙 그림자. 없으면 색배경+제목 합성. 영화 포스터는 `dphoto` 변형(하단 어둠 그라디언트 + textShadow). [수치는 Explore 인용 — 미직접확인] |
| **평점 행** | `44px 1fr auto` 그리드, min-height 64. hover 배경만, 선택 시 좌측 2.5px 인디케이터 바. |
| **필터 칩 / 세그먼트** | 칩 999px(전체/영화/책). 세그먼트 토글(영화/책 탭)은 그림자로 active. |
| **검색 인풋** | line 보더 + r-sm + inset shadow, focus accent 2px ring + 16% alpha. placeholder ink-4. |
| **빈/로딩/에러 상태** | 빈 = 한 줄 안내 + 유도 버튼. 로딩 = skeleton. 에러 = danger plain text + role=alert. |
| **점수 배지**(목록 요약용) | study **ScorePill** 차용: pill, 숫자 mono+gold, "추천" 이상은 sage 톤. |

## 4. 인터랙션

- 별점: 별 위 마우스 호버 시 채움 미리보기, 클릭 확정. 좌반=−0.5, 우반=정수. 모바일은 탭(반쪽은 길게 눌러 미세조정 또는 0.5 스텝 슬라이더 대체 — Claude Design 판단).
- 검색: 입력 디바운스 350ms → 결과. 선택 시 별점 패널 인라인 전개.
- 추천 카드: 액션 링크는 새 탭(왓챠/알라딘). "관심 없음"은 비범위(§7).
- 모션: 콘텐츠 이동 없이 인터랙션 피드백만 150~250ms(hover lift, 패널 전개, 토스트 슬라이드).

## 5. 데이터 샘플 (목업에 진짜 한국어로 — 로렘 금지)

Claude Design 시안에는 아래처럼 **실재 작품 + 자연스러운 추천 이유**를 넣어 줄바꿈·자간·clamp를 실제처럼 검증한다.

> ⚠ **미검증 예시**: 아래 작품의 연도·저자·교차매칭은 기억 기반이라 정확성 미검증이고, 지오의 실제 평점도 아니다(시안 채움용 더미). 실제 작품 메타는 구현 시 TMDB(영화)·알라딘(책) 조회로 확정한다.

- 영화 평점 예: «기생충»(2019) ★5.0 · «헤어질 결심»(2022) ★4.5 · «패스트 라이브즈»(2023) ★4.5 · «어바웃 타임»(2013) ★3.5 · (비추 예) «모비우스»(2022) ★0.5.
- 책 평점 예: «데미안»(헤르만 헤세) ★4.5 · «사피엔스»(유발 하라리) ★4.0 · «미움받을 용기»(기시미 이치로·고가 후미타케) ★3.0.
- 추천 카드 예(이유 포함):
  - 영화 «드라이브 마이 카»(2021) — "«헤어질 결심»에 5점 가까운 별을 주셨죠. 절제된 호흡과 상실을 응시하는 시선이 닿아 있습니다." → 왓챠에서 보기
  - 책 «랩 걸»(호프 자런) — "«사피엔스»처럼 과학을 이야기로 풀어내되, 더 사적인 온도. 영화 «패스트 라이브즈»의 잔잔함과도 통합니다." → 알라딘에서 보기

## 6. 반응형

- **데스크톱 주력(≥1025):** `max-width:1240` 중앙 페이지. 추천 그리드 `repeat(auto-fit, minmax(280px, 1fr))`(§2.1과 동일). 내 평점은 검색/목록 2영역.
- **태블릿(≤1024):** 그리드 2열, 패딩 축소.
- **모바일(≤768):** 단일 컬럼, 추천 카드 세로 스택(포스터 위/메타·이유 아래), 상단 세그먼트 또는 하단 탭바. 터치 타겟 ≥44px, `100dvh` + safe-area.

## 7. 비범위 (디자인 시안에서 빼기)

OTT 실시간 가용성 뱃지, 예상 별점 수치, 통계 대시보드, 부부 취향 비교, 추천 dismiss/히스토리, 설정 화면. (전부 후순위 — 시안은 핵심 4화면만.)

## 8. Claude Design 사용 절차 (지오용)

1. claude.ai 좌측 사이드바 팔레트 아이콘 → Claude Design.
2. 온보딩에 `~/apps/DESIGN.md` + `book/src/styles/book.css` + `study/src/styles/session.css` 첨부(디자인 시스템 흡수).
3. 이 브리프(`taste-design-brief.md`) 전문을 프롬프트로 입력 + "데스크톱 주력, 모바일 대응, 4앱 절제 무드" 강조.
4. 화면별로 반복: 추천(홈)부터 → 내 평점 → 가져오기 → 로그인.
5. 완성 시 **핸드오프 번들** 생성 → Wave 1 구현 시 Claude Code가 참조.
