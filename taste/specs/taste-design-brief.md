# taste — 디자인 작업지시서 v2 (Claude Design 입력용)

> 이 문서는 Anthropic **Claude Design**(claude.ai 사이드바 → 팔레트)에 입력해 taste 앱 UI 시안(실행가능 HTML/CSS/JS)을 생성하기 위한 작업지시서다.
> 기능·데이터 설계는 `taste-app-spec.md`(디자인 확정 후 갱신 예정), 디자인 토큰은 첨부 CSS 참조.
> **확정 방향:** 데스크톱 주력 + 모바일 대응(반응형), 4앱 디자인 언어 충실(절제).

## ★ v1 → v2 핵심 변경 (왜 다시 그리는가)

v1 시안(추천/내 평점 2탭)은 **검색이 "내 평점>책 탭"에만 숨고, 추천이 주 1회**였다. 사용자 의도는 정반대다:

1. **사용자 액션은 단 둘** — (A) **추천 소비**(보러 가기) (B) **평가 입력**(검색→별점). 나머지(가져오기·로그인)는 부수.
2. **외부 링크 제거** — "왓챠/알라딘에서 보기" 없앤다. **taste 안에서 모든 작품 정보를 소비**한다.
3. **작품 상세 페이지 = 허브 신설.** 검색·추천에서 작품을 열면 API 메타(영화: 출연·감독·극본·줄거리 / 책: 저자·요약)를 보여주고, 그 아래 **Claude가 취향 분석한 "이 작품과 통하는 다른 작품 브랜치 추천"**으로 가지치며 탐색.
4. **추천 두 층위** — 작품 상세의 **브랜치**(이 한 작품 기점, 로컬) + 홈의 **메인 추천**(평가한 전부를 취합, 글로벌).
5. **AI 생성 콘텐츠 = 평가 후 10분 뒤.** today 자동댓글 데몬의 settle 패턴(`navi-realtime-daemon.mjs`) 차용 — 새 별점이 들어오면 10분 settle 후 브랜치·메인 추천을 (재)생성.

## 0. 한눈에

**제품:** taste — 내가 별점 평가한 영화·책에서 출발해 Claude가 "다음에 볼/읽을 것"을 이유와 함께 추천하는 개인용 PWA. 부부가 각자 자기 계정으로 자기 추천을 받음(데이터 개인 격리).

**디자인 목표:** 기존 4앱(study/gym/today/book)과 한 가족처럼 보이는 절제된 웜그레이 UI. 포스터·표지는 색을 가져오되 전면을 점령하지 않음. "차분한 서재에서 다음 작품을 고르고, 한 작품에서 다음 작품으로 가지를 타는" 무드.

**화면 맵 (v2):**
| 화면 | 한 줄 | 역할 |
|---|---|---|
| **홈** | 상단 **상시 검색** + **메인 추천 피드**(평가 전부 취합) | 소비 + 평가 입구 |
| **작품 상세** | 메타(API) + 별점 + **취향 브랜치 추천** | 허브 — 평가·소비·탐색 |
| [부수] 내 평점 | 내가 매긴 것 모아보기 | 메뉴 구석 |
| [부수] 가져오기 | 왓챠 CSV(콜드스타트 1회) | 온보딩 |
| [부수] 로그인 | Google OAuth | — |

**핵심 흐름:**
```
홈(검색/메인추천) ─→ 작품 상세 ─┬─ 메타: 영화(출연·감독·극본·줄거리) / 책(저자·요약)
                               ├─ 별점 (평가 입력)
                               └─ 취향 브랜치 추천 ──→ 다음 작품 상세 (가지치기)
        평가 → 10분 settle → 브랜치 생성 + 메인 추천 재생성
```

## 2. 화면별 사양

### 2.1 홈 — 상시 검색 + 메인 추천 피드

- **최상단: 검색 바(상시, sticky).** line 보더 + inset shadow + 돋보기 아이콘. **포커스/호버 시 드롭다운**: 위에 "최근 검색"(텍스트 칩 몇 개), 아래 "기본 결과"(인기/추천 작품 몇 개). **입력하면** 영화·책 **통합 결과 행**(포스터 썸네일 44px + 제목·메타). 결과 행 클릭 → **작품 상세**로 이동(검색 행에서 바로 별점 매기는 단축은 없음).
- **본문: 메인 추천 피드.** 페이지 타이틀 "추천" + 한 줄 설명("평가한 모든 작품에서 길어 올린 다음 작품"). 필터 칩(전체/영화/책). **추천 카드 그리드** `repeat(auto-fit, minmax(280px,1fr))`, `max-width:1240` 중앙.
- **추천 카드**: 포스터/표지 + 제목·메타 + **추천 이유**(serif, 2~3줄, 주인공) + "당신이 ★4.5 준 «X»에서 출발" 작은 라벨. **외부 링크 없음** — 카드 클릭 = 작품 상세로 이동.
- **빈 상태(콜드스타트, 평점 0):** "아직 평가한 작품이 없어요. 위에서 검색해 별점을 매기거나, 왓챠 기록을 가져오세요." + [가져오기] 버튼.

### 2.2 작품 상세 — 허브 (★ 신규 핵심 화면)

검색 결과·메인 추천 카드·브랜치 추천 어디서든 작품을 열면 이 페이지. **2단계 상태**:

**① 평가 시점 (메타 + 별점, AI 콘텐츠 아직 없음)**
- 상단: **큰 포스터/표지**(좌) + 제목·원제·연도(우).
- **메타 블록**(API):
  - 영화: **주요 출연진**(상위 4~6명, 배우명) · **감독** · **극본** · **줄거리**(serif 본문).
  - 책: **저자**(이름+역할) · **출판사·연도** · **책 요약**(serif 본문).
- **별점 위젯**(0.5단위 + 앵커 라벨, 0.5★=비추) — 여기서 평가. 저장 시 "10분 뒤 이 작품과 통하는 추천이 도착해요" 안내.
- 그 아래 **브랜치 영역 = 빈/대기 상태**: "취향을 분석하고 있어요 — 평가 10분 뒤 이 작품에서 뻗는 추천이 채워집니다." (은은한 skeleton/placeholder, 재촉 아님)

**② 평가 10분 후 (브랜치 채워짐)**
- 브랜치 영역에 **"이 작품과 통하는 다른 작품"** 추천 카드들(취향 기반). 각 카드 = 포스터 + 제목 + 짧은 연결 이유("«이 영화»의 절제된 호흡과 닿아요"). **카드 클릭 → 그 작품 상세**(가지치기 탐색).
- 영화↔책 교차도 가능(영화 상세에서 통하는 책 추천).

> 미평가 추천작도 같은 페이지가 열린다(메타 + "별점 매기기" 노출). 평가 여부와 무관한 허브.

### 2.3 부수 화면 (메뉴 구석, 절제)

- **내 평점**: 내가 매긴 영화·책 모아보기(세그먼트 탭 + 별점 행 + 삭제). 정렬 최신/별점순.
- **가져오기**: 왓챠 CSV 업로드(콜드스타트 1회). 드롭존 → 미리보기 → 저장.
- **로그인**: 중앙 카드 + Google 버튼.

## 4. 인터랙션

- **검색:** 바 포커스 → 드롭다운(최근+기본). 입력 디바운스 350ms → 통합 결과. 결과 클릭 → 작품 상세.
- **평가:** 작품 상세 별점 클릭(호버 미리보기 → 클릭 확정) → 저장. **저장 후 10분 settle** → 브랜치 생성 + 메인 추천 재생성(사용자엔 "곧 도착" 안내, 자동 갱신).
- **탐색(가지치기):** 브랜치 카드·추천 카드 클릭 → 다음 작품 상세. 뒤로가기로 가지 되짚기.
- **모션:** 콘텐츠 이동 없이 피드백만 150~250ms. 브랜치 도착은 부드러운 fade-in.

## 5. 데이터 샘플 (진짜 한국어로 — 로렘 금지)

> ⚠ **미검증 더미**: 아래 출연/연도/줄거리는 시안 채움용이고 지오 실제 평점도 아니다. 실제 메타는 구현 시 TMDB/알라딘으로 확정.

- **작품 상세 예 (영화):** «헤어질 결심»(2022) · 감독 박찬욱 · 극본 정서경·박찬욱 · 출연 박해일·탕웨이 · 줄거리 "산 정상에서 추락사한 남자의 사건을 수사하던 형사가 그의 아내를 만나며…" · 내 별점 ★4.5(최애). 브랜치 → «드라이브 마이 카»(2021) "상실을 응시하는 절제된 호흡이 닿아요" / 책 «작별하지 않는다»(한강) "떠난 사람을 붙드는 시선".
- **작품 상세 예 (책):** «사피엔스»(유발 하라리·조현욱 옮김 · 김영사 2023) · 요약 "인지혁명에서 과학혁명까지 인간 역사의 대담한 질문…" · 내 별점 ★4.0(최애). 브랜치 → «총 균 쇠»(재레드 다이아몬드) / 영화 «컨택트»(2016) "문명과 언어를 다르게 보게 하는".
- **메인 추천 예:** 영화 «패스트 라이브즈»(2023) — "«헤어질 결심»에 가까운 별을 주셨죠. 인연과 시차를 응시하는 잔잔함이 통합니다."

## 6. 반응형

- **데스크톱(≥1025):** `max-width:1240` 중앙. 작품 상세 = 포스터 좌(고정폭) + 메타·브랜치 우. 메인 추천 그리드 `auto-fit minmax(280px,1fr)`.
- **태블릿(≤1024):** 2열, 패딩 축소.
- **모바일(≤768):** 단일 컬럼. 작품 상세 = 포스터 위/메타 아래 스택. 검색 바 sticky 유지. 터치 ≥44px, `100dvh`+safe-area.

## 7. 비범위 (시안에서 빼기)

외부 OTT/구매 링크(**제거 확정**), 예상 별점 수치, 통계 대시보드, 부부 취향 비교, 추천 dismiss/히스토리, 설정. 시안은 **홈 + 작품 상세** 두 핵심 화면에 집중(부수 화면은 가벼운 스텁).
