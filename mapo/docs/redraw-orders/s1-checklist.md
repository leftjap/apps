# 단계 S1(마포 전역 정적 바닥) 검수 목록

합정·서교·홍대 일대(H2~H5)에서 놓쳤거나 지오가 짚은 것을 모았다. 근거는 `docs/area-recipe.md` 의 「큰길의 차로·인도를 사진과 대조한다」(91~103행), 「두 번째 구역: 서교동사거리」(243~264행), 「H2」(75~81행), 「아직 풀지 않은 것」(323~334행). 마스터와 검수 CLI 는 항목마다 직접 본 것과 보고로 받은 것을 가려 적는다. 수치 통과는 승인을 대신하지 않는다.

## 자료를 만든 직후 (s1-bake)
1. 윤곽이 교차로 면·횡단면·정지선·교차로 연결선을 자르지 않는다(H3 에서 행정동 경계를 그대로 써 독막로 들머리를 잃었다).
2. 높이 없는 건물 0, 윤곽 밖 0㎡, 건물과 찻길·인도 겹침 0㎡, 지도 조각 경계에 변이 놓인 건물·인도 면 0.
3. 섬은 규칙으로만 가린다(번호 예외 금지). 서교에서는 규칙이 후보 일곱을 모두 떨어뜨렸다. 새 범위에서 남은 섬 수와 떨어진 까닭별 수를 본다.
4. A2 가 없는 길(신촌 연세로·이화여대길·명물길, 성산 잔다리로, 모래내로·만리재로 일부)은 차선·화살표가 비어 사진과 다르다(서교 교차 도로와 같은 일). 그런 길의 길이를 세어 둔다.
5. 공원·녹지 바깥선은 수치지형도에 없어 OpenStreetMap 으로 칠했다(홍대 일대 23.4만㎡). 새 범위의 공원(월드컵공원, 하늘·노을공원, 난지, 경의선숲길 전 구간)이 대지 색으로 비지 않는지 본다. 화면 출처 문구도 그대로인지.
6. 운동장이 대지 색, 찻길 옆 나무 띠가 대지 색으로만 남는 것: 이미 아는 것이라 세기만 한다.

## 화면에 띄운 뒤 (칸으로 나눈 뒤)
7. 가까운 배율(폭 60~200m), 중간(600~1,500m), 전체 보기, 모바일을 실제 GPU 로 본다. I2 는 폭 120m 만 봐서 폭 700m 에서 차선·횡단보도가 사라진 화면이 통과했다.
8. 멀리 볼수록 칠이 한 픽셀 굵기로 남아 차로를 가리지 않는다(H4: 폭 400m 에서 칠이 차로 폭의 12~15%).
9. 빗금 안전지대가 빗금으로 그려진다(테두리 선만 있으면 폭 2m 짜리 차로처럼 보인다). 중앙 노란 빗금 띠가 절반만 그려진 자리(H5 R01-139)가 새 범위에도 있는지.
10. 방향 화살표(B3)가 그려진다.
11. 칸 경계에서 바닥·칠·건물이 끊기거나 겹쳐 깜박이지 않는다. 물 없는 지도 조각 두 곳이 주황으로 남지 않는다.
12. 기존 화면(구역 넷, `yanghwa-map`, `hongdae-district`)의 캡처가 바뀌지 않는다.

## 사진 대조 (`tools/v2/road_audit.py --area mapo-all`)
13. 큰길마다 가운데선을 따라 40m 마다(강변북로·양화로는 20m) 80m 칸, 교차로·길 중간 횡단·승강장은 따로. 칸마다 항공사진 | 모형 평면도 | 겹친 그림(연석 빨강, 노면선 하늘색, 정지선 자홍, 횡단보도 노랑). 합정 사거리를 같은 방법으로 떠 눈금으로 삼는다.
14. 길마다 칸을 직접 넘겨 본다(H4·H5 에서 Claude 가 직접 본 칸은 스무 칸 남짓이었고 지오가 「대충 코드만 훑어본다」고 지적했다). 자동 판독은 후보를 고르는 데만 쓴다.
15. 볼 것: 차로 수, 차로 폭이 갑자기 좁아지는 구간(지오가 합정 밖에서 짚은 것), 차로 구분 칠 빠짐, 연석·정지선·횡단보도 자리, 인도 폭(공원·녹지·산책로 옆에서 모형이 넓은 대지나 곧은 띠로 그린 칸이 H5 에서 다섯).
16. 높이가 다른 길(강변북로, 나들목, 고가, 다리)은 땅 높이로 겹쳐 그려진다. S1 에서는 목록만 만들고(H5 는 172칸) 다음 단계에서 높이별로 나눈다.
17. 버스 차로 붉은 포장은 자료에 끝나는 자리가 없어 보류 중이다. 새로 만들지 않는다.
18. 건물은 큰길가와 유동인구가 많은 쪽(홍대 관광특구, 신촌, 합정, 공덕)을 먼저 본다(지오 2026-11-25).

## 사람·차 단계로 넘기기 전에 (S1 에서는 세기만)
19. 골목 입구마다 인도가 끊겨 걷는 그물이 여러 덩어리가 되는지(서교 20덩어리). 덩어리 수와 큰 덩어리에 붙은 출입 자리 수를 그림으로 본다.
20. 오목한 인도 모퉁이 수(합정 49곳 → 0).
21. 두 A2 선이 차 폭보다 가까운 나란한 회전 차로 쌍.
