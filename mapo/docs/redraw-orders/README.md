# 다시 그리기 진행 안내 (기획 세션용)

기준은 `docs/redraw.md` 다. 이 파일은 기획 세션이 바뀌어도 이어서 진행할 수 있게 지금 상태와 일하는 방법을 적는다. 단계가 끝날 때마다 「진행 현황」을 고친다.

## 역할

- **기획 세션**: 지시서를 쓰고, 구현 세션을 시작하고, 결과 화면을 먼저 열어 검수하고, 통과한 것만 지오에게 보낸다. 규칙이 맞지 않으면 `docs/redraw.md` 를 먼저 고친다. 코드를 직접 고치지 않는다.
- **구현 세션**: 지시서 하나를 받아 그대로 만든다. 정해지지 않은 선택은 스스로 하지 않고 멈춰서 묻는다.
- 구현 세션은 한 번에 하나만 돌린다. 지시서 하나가 한 단계다.

## 진행 현황

| 단계 | 상태 | 지시서 |
|---|---|---|
| 0 자료 확인 | 끝남(2026-11-22) | 없음(기획 세션이 직접, `tools/v2/audit0.py`) |
| 1 땅 나누기 시안 | 지시서 씀, 구현 전 | `1-land.md` |
| 2 도로 부지 안 나누기 | 지시서 없음 | 1단계 화면 승인 뒤 씀 |
| 3 차로와 표시 | 지시서 없음 | |
| 4 판 전체 | 지시서 없음 | |
| 5 차량 / 6 사람 / 7 장면 | 지시서 없음 | 시작 전 `docs/redraw.md` 에 그 단계 규칙 절을 더한다 |

## 구현 세션을 시작할 때

- 지시서 경로와 「`docs/redraw.md` 와 지시서를 처음부터 끝까지 읽고 시작」을 지시문 첫 줄에 적는다.
- 지시문에 넣을 것: 작업 폴더 `~/apps/mapo`, `mapo/CLAUDE.md` 의 저장소 규칙, 미리보기 도구 금지, 커밋 꼬리말, 보고 형식(다섯 줄).
- 구현 세션이 물어 오면 기준 문서로 답할 수 있는지 먼저 보고, 없으면 문서에 규칙을 더한 뒤 답한다. 지오가 정할 일(자료를 바꾸는 것, 6절의 값을 바꾸는 것, 범위를 넓히는 것)은 지오에게 묻는다.

## 결과를 검수할 때 (지오에게 보내기 전)

1. 보고의 숫자가 아니라 그림을 `Read` 로 직접 연다. 구역 전체와 아홉 장을 모두 본다.
2. `check_land.py` 가 찍은 경계 거리(2m 넘는 비율)를 보고, 측량 자료 대조 그림에서 우리만(빨강)·측량만(파랑)이 띠로 길게 이어지는 곳을 찾는다. 2m(큰길)·1m(골목) 넘게 벗어난 곳이 있으면 그 자리를 고치게 하지 말고, 그 차이를 만든 규칙이나 `docs/redraw.md` 6절의 값을 고친다.
3. 카카오맵과 나란히 놓는다: 디버그 크롬(`~/.claude/scripts/chrome-debug.sh`, 9333, `new_page` 에 `background: true`)으로 카카오맵을 같은 범위로 열어 화면을 찍고, 우리 그림과 옆에 붙인다. 이 절차는 아직 해 보지 않았다. 처음 할 때 되는 방법을 여기에 적는다. 카카오맵 화면은 저장소에 올리지 않는다.
4. `docs/redraw.md` 12절의 질문 가운데 이번 그림으로 답할 수 있는 것을 답하고 문서를 고친다.
5. 지오에게는 그림과 다섯 줄 안쪽 설명, 지오가 정할 것(있으면)을 보낸다. 지오가 승인하면 다음 지시서를 쓴다.

## 1단계 화면에서 지오가 정할 것

- 건물이 도로 부지 안으로 1~4m 들어온 띠(도로 부지의 2.7%): 지시서 1은 건물을 남긴다. 그림을 보고 도로 부지를 남기는 쪽이 나은지 정한다.
- 도로 부지가 없는 길을 표준 폭 띠로 채운 곳이 어색한지.

## 가진 자료와 도구

- 도로 부지: `tools/raw/gis-roads.json`(실폭도로). 건물: `public/data/board.json`.
- 측량 자료(로컬 대조용, 커밋 안 함): 수치지형도 12도엽 `tools/raw/ngii/suchi/sheets/`(시제품 구역만), 정밀도로지도 `tools/raw/ngii/hd-lines.json`. 판 전체로 넓힐 때는 수치지형도 도엽을 더 받아야 한다(국토정보플랫폼 로그인은 지오가 한다. 받는 요령은 기획 세션 메모리 `mapo-redraw-2026-11` 에 있다).
- `tools/v2/shp.py`(SHP 읽기), `tools/v2/tm.py`(좌표 변환), `tools/.venv`(shapely).

## 지오가 한 말 가운데 지켜야 할 것

- 지도는 「대충 이렇게 생겼다」가 깔끔하게 보이면 된다. 정밀도를 올리는 작업을 스스로 시작하지 않는다.
- 추측하지 말고 자료를 확보해 대조한다. 다만 자료 여러 개를 서로 맞추지 않는다.
- 묻는 것은 지오만 정할 수 있는 일로 줄이고, 권장을 붙인다. 세션 운용은 스스로 판단한다.
- 기획은 높은 등급 모델, 구현은 Opus 5.5 로 한다. 구현 세션이 판단할 일을 남기지 않는다.
