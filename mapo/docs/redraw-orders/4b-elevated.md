# 지시서 4b: 고가·다리를 같은 규칙에 넣는다

기준 문서 `docs/redraw.md`(9판)를 처음부터 끝까지 읽고 시작한다. 이 지시서와 기준 문서로 정해지지 않는 선택이 나오면 스스로 정하지 말고 멈춰서 묻는다. 이 지시서에 없는 파일은 고치지 않는다. 지시서 4a(65f272e9)의 결과는 검수를 통과했다.

## 목표

지금 굽기는 땅 위 중심선(높이 0.3m 아래)만 쓴다. 그래서 높이 0.3m 이상인 큰길 15km(내부순환로, 강변북로, 서강대교, 양화대교, 연결로 등)가 차로 없는 띠로 나온다. 이 큰길도 땅 위 길과 **같은 규칙**(찻길·인도·차로·표시)으로 굽는다. 2D 자료만 만든다. 고가를 3D 화면에서 높이 올려 그리는 일은 이 지시서의 범위가 아니다(다음 지시서). 그래서 높이가 다른 두 길이 엇갈리는 자리에서는 두 길의 차선이 한 평면에 겹쳐 그려진다. 그대로 둔다.

## 규칙 (기준 문서 4절 3·4, 6절)

1. **큰길(등급 0~3) 중심선은 높이와 상관없이 모두 쓴다.** 골목(등급 4·5)과 보행 전용(등급 6)은 지금처럼 땅 위(양 끝 높이 0.3m 아래) 선분만 쓴다.
2. **엇갈리는 선의 높이가 3m 이상 다르면 서로 없는 것으로 본다.** 차로 단면에서 다른 구간의 선이 30° 넘게 다른 방향으로 지나가면 지금은 「교차로 안」이다. 그 자리에서 두 선의 높이 차가 3.0m 이상이면 교차로 안으로 보지 않고, 그 선으로 폭을 나누지도 않는다(그 선을 건너뛴다). 방향이 30° 안으로 나란한 선은 높이와 상관없이 지금처럼 폭을 나눈다(고가 바로 밑으로 같은 방향의 땅 위 길이 지나가는 곳에서 두 길이 폭을 나눠 갖는다).
3. **높이 3m 이상인 자리에는 정지선과 횡단보도를 놓지 않는다.** 교차로 입구의 것도, 구간 중간 횡단보도도 놓지 않는다.

## 기획 세션이 저장소 밖 사본에서 먼저 돌려 본 것 (2026-11-22)

4a 의 코드에 규칙 1·2 를 넣어 돌렸다(규칙 3 은 넣지 않고 수만 셌다). 굽기 넷은 오류 없이 끝났고 검사 넷은 모두 PASS 였다. 시간은 split 15.3초, lanes 13.3초, marks 13.5초였다.

| 굽기 | 사본에서 나온 수 |
|---|---|
| split | car 24개 1,037,008㎡, walk 1,210개 285,960㎡, mix 376개 1,042,551㎡, ped 75개 44,016㎡ |
| lanes | 구간 388개(79.87km), 차로를 둔 구간 214개, 차로 가운데선 928개 |
| marks | 중앙선 163, 차선 601, 흰 실선 58, 정지선 520, 횡단보도 433 |

- 엇갈리는 큰길 선분 쌍(끝점을 함께 쓰지 않는 것) 70개의 높이 차: 0m 21개, 3.3m 와 4.6m 각 1개, 5m 이상 47개. 0 과 3.3 사이에는 없다.
- 같은 자리(x, z)에 높이가 0.3m 넘게 다른 큰길 꼭짓점은 0개다(노드를 2D 좌표로 묶어도 된다).
- 규칙 3 에 걸리는 것: 횡단보도 8개, 정지선 12개(가장 가까운 큰길 중심선의 높이로 센 값).
- 서강대교·양화대교·강변북로·내부순환로에 차로가 놓였고, 서강대교가 강변북로 위를 지나는 자리에서 차로가 끊기지 않았다(그림으로 확인).
- 서로 다른 구간의 차로 가운데선이 만나는 곳은 300곳으로 늘었다(4a 는 11곳). 높이가 다른 길이 엇갈리는 자리가 대부분이다.

수가 위 표와 조금 달라도 된다(구현 방식에 따라, 그리고 규칙 3 때문에 정지선·횡단보도가 준다). 다각형 수나 넓이, 구간 수가 10% 넘게 다르면 멈추고 보고한다.

## 바꿀 것

1. **`tools/v2/split.py`**: `ground_chains()` 가 땅 위 선분만 잇는다. 등급 0~3 인 길은 모든 선분을 잇고, 등급 4~6 인 길은 지금처럼 양 끝 높이가 0.3m 아래인 선분만 잇는다. 함수 이름과 설명 글은 뜻에 맞게 고친다. 그 밖의 규칙은 바꾸지 않는다.
2. **`tools/v2/lanes.py` 구간 만들기**: `build_sections()` 에서 큰길 선분을 높이로 거르는 조건(`s[1] < 0.3 and e[1] < 0.3`)을 없앤다. 구간마다 선의 꼭짓점 높이를 선의 꼭짓점과 같은 순서·개수로 함께 둔다(`ys`). 구간 선 위 거리 d 의 높이는 앞뒤 꼭짓점 높이를 거리로 곧게 이어 구한다. 판 테두리에서 잘린 끝의 높이도 같은 방법으로 구한다.
3. **`tools/v2/lanes.py` 단면(`Cutter.cut`)**: 값 `LEVEL_GAP = 3.0` 을 파일 위쪽 값 목록에 더한다. 단면 조각이 다른 구간 선과 만나는 점마다 지금 하는 방향 판정에 더해:
   - 내 구간 선의 높이는 단면 가운데 점(거리 d)의 높이다. 다른 구간 선의 높이는 만나는 점의 거리 `t0` 자리 높이다.
   - 방향이 `JUNCTION_DEG` 넘게 다르고 높이 차가 `LEVEL_GAP` 이상이면 그 점을 건너뛴다(「교차로 안」도 아니고 폭도 나누지 않는다).
   - 방향이 `JUNCTION_DEG` 넘게 다르고 높이 차가 `LEVEL_GAP` 아래이면 지금처럼 「교차로 안」이다.
   - 방향이 `JUNCTION_DEG` 안이면 높이와 상관없이 지금처럼 폭을 나눈다(opp·same 판정도 그대로).
   - 폭을 재는 단계와 차로 단면 단계가 같은 `cut()` 을 쓰므로 둘 다에 적용된다.
4. **`tools/v2/lanes.py` 출력**: `lanes.json` 의 구간마다 `ay` 를 더한다: `axis` 의 점마다 높이(dm 정수, `axis` 의 점 수와 같은 개수). `v` 를 3 으로 올린다. `lanes.json` 의 `v` 를 확인하는 곳(`marks.py`, `check_*.py`, `plot_*.py`)이 있으면 3 으로 고친다.
5. **`tools/v2/marks.py`**: 값 `HIGH = 3.0` 을 더한다. 구간 선의 높이는 `lanes.json` 의 `axis`·`ay` 로 구한다(2와 같은 내삽).
   - 교차로 입구(끝 종류 `n`·`j`): 차로 끝 자리의 구간 선 높이가 `HIGH` 이상이면 그 입구에 정지선과 횡단보도를 놓지 않는다.
   - 구간 중간 횡단보도: 놓을 자리의 구간 선 높이가 `HIGH` 이상이면 놓지 않는다(그 서울시 횡단보도는 쓰이지 않은 것으로 둔다).
   - 빠진 정지선과 횡단보도의 수를 한 줄로 찍는다.
6. **검사**:
   - `check_lanes.py` 의 찍는 수치 「서로 다른 구간의 차로 가운데선이 만나는 곳」을 둘로 나눠 찍는다: 만나는 점에서 두 구간 선의 높이 차가 3m 아래인 곳과 3m 이상인 곳. 3m 아래인 곳은 자리(좌표)를 모두 찍는다.
   - `check_marks.py` 에 PASS/FAIL 항목 하나를 더한다: 가운데 점에서 가장 가까운 구간 선의 높이가 3m 이상인 정지선과 횡단보도가 0개.
   - 다른 PASS/FAIL 항목은 바꾸지 않는다. 검사가 땅 위 중심선만 읽어서 규칙과 어긋나게 재는 곳이 있으면(자료가 규칙대로인지 한두 곳을 직접 조회해 확인한 뒤) 검사를 고치고 보고에 적는다.
7. **그림**: `plot_split.py`·`plot_lanes.py`·`plot_marks.py` 의 확대 그림 목록(`ZOOM`)에 아래를 더한다(범위와 배율은 지금 확대 그림과 같게).

   | 이름 | 가운데 (x, z) | 무엇 |
   |---|---|---|
   | `seogangbr` | (800, 950) | 서강대교 북단과 강변북로 |
   | `yanghwabr` | (−850, 550) | 양화대교 북단 |
   | `naebu` | (−1250, −1330) | 내부순환로와 월드컵로 |
   | `morae` | (−100, −1800) | 모래내고가도로 |

## 순서

1. `node tools/v2/roads_json.ts` (바꾸지 않는다. `tmp/v2/roads.json` 을 새로 만든다). `land.py` 는 바꾸지 않고 다시 돌리지도 않는다.
2. 바꿀 것 1 → `split.py` → `check_split.py` → `plot_split.py`.
3. 바꿀 것 2·3·4 → `lanes.py` → `check_lanes.py` → `plot_lanes.py`.
4. 바꿀 것 5 → `marks.py` → `check_marks.py` → `plot_marks.py`.
5. 굽기 넷(land 는 4a 때의 3.4초)의 시간을 합쳐 적는다. 1분을 넘으면 멈추고 보고한다.

검사가 FAIL 을 내면: 검사가 재는 방식이 규칙과 어긋난 것이면 검사를 고치고 계속하고 보고에 적는다. 만드는 규칙이 원인이면 고치지 말고 멈춰서 자리와 수를 보고한다.

- `tools/v2/split.py`·`lanes.py`·`marks.py`·`check_lanes.py`·`check_marks.py`·`plot_split.py`·`plot_lanes.py`·`plot_marks.py` 와 `public/data/v2/` 의 `split.json`·`lanes.json`·`marks.json` 말고는 만들거나 고치지 않는다(6의 「검사를 고치고 보고」에 해당하는 `check_split.py` 는 예외). `src/`, `test/`, `land.py`, 옛 도로 코드와 옛 자료를 고치지 않는다.
- 고가를 높이 올려 그리지 않는다. 고가 밑 땅을 따로 다루지 않는다. 도로 부지가 없는 성산로를 채우지 않는다.
- 6절의 다른 값과 1~3단계의 규칙을 바꾸지 않는다. 결과가 어색한 곳은 자리(좌표)를 보고에 적는다.
- `tools/raw/`, `tmp/` 를 커밋하지 않는다. 굽기(`pnpm bake`), 전체 `pnpm test`, 하위 에이전트를 쓰지 않는다.

## 검수 세션이 볼 것 (구현 세션은 고치지 않는다)

1. 서강대교, 양화대교, 강변북로, 내부순환로, 모래내고가도로에 찻길과 차로가 놓였는지, 다리 위에서 차로가 끊기거나 정지선·횡단보도가 남은 곳이 있는지(`*-zoom-seogangbr`·`yanghwabr`·`naebu`·`morae`, 3D 화면).
2. 높이가 다른 길이 엇갈리는 자리에서 아래 길과 위 길의 차로가 둘 다 끊기지 않고 지나가는지. 끊긴 자리가 있으면 좌표와 두 길의 높이를 적는다.
3. 고가 바로 밑으로 같은 방향의 땅 위 길이 지나가는 곳(모래내고가도로, 서강대교 북쪽 서강로)에서 두 길이 폭을 나눠 가진 모양이 어색한지.
4. 고가가 아닌 곳이 4a 와 같은지: `marks.json` 을 65f272e9 와 견줘, 고가 선에서 60m 넘게 떨어진 곳의 선·횡단보도가 옮겨졌는지(4a 검수의 `cmp3.py` 와 같은 방법).
5. 높이 차가 3m 아래인데 서로 다른 구간의 차로가 만나는 곳의 수가 4a(11곳)에서 늘었는지, 늘었다면 어디인지.
6. 4a 검수에서 본 성산로 둘레(차로 없는 폭 19m 찻길 띠)와 마포구청역 둘레가 어떻게 달라졌는지.

## 끝나는 조건과 보고

- 굽기와 검사가 끝나고(FAIL 0), 그림과 3D 화면 넷이 생겼고 `pnpm build` 가 끝나면, 바꾼 `tools/v2/` 파일과 `public/data/v2/` 의 세 자료만 커밋하고 푸시한다. 커밋 직전에 `pnpm test:map` 을 한 번 돌리고 요약 줄만 읽는다. 커밋 전 `git log --oneline -1` 로 WIP 스냅샷 커밋이 끼었는지 본다. `git stash`·`reset --hard`·브랜치 전환·force push 금지. 커밋은 다른 명령과 붙이지 말고 따로 짧게 실행한다.
- 보고는 열 줄 안쪽, 맨 앞에 커밋 해시: 굽기마다 걸린 시간과 찍힌 수(위 표와 견줘), 검사 결과, 규칙 2로 건너뛴 점의 수, 규칙 3으로 빠진 정지선·횡단보도의 수, 높이 차 3m 아래에서 만나는 차로의 수, 자료 세 파일의 크기, 3D 화면의 오류 수, 눈에 띈 것. 자세한 것은 공유 메모 폴더에 `stage4b-impl-2026-11-22.md` 로 적는다.
- 같은 문제를 두 번 고쳐도 안 되면 멈추고 원인을 보고한다.
