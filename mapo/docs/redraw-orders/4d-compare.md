# 지시서 4d: 대조 자리 열 곳 (검수 세션)

코드와 자료를 고치지 않는 검수 지시서다. 4단계의 지오 승인을 받을 그림을 만든다(`docs/redraw.md` 7절·9절). 지금 자료는 185b6670 이다.

## 하는 일

`docs/redraw.md` 7절의 대조 자리 열 곳마다:

1. **자리 정하기**: 판 좌표 (x, z) 를 자료로 정한다. 지하철 역·출구(`board.json` 의 `stations`·`exits`), 길 이름(`board.json` 의 `r` 과 `names`), OSM 광장 면을 쓴다. 이미 쓴 자리: 합정 사거리 (−490, 245), 홍대입구역 (670, −830), 걷고싶은거리 (640, −560), 상수역 사거리 (343, 415), 서강대교 북단 (800, 950), 망원역 (−783, −502). 나머지 넷(동교동 삼거리, 클럽 거리(와우산로 일대), 연남동 경의선숲길, 회전교차로 한 곳)은 카카오맵에서 이름으로 찾은 위도·경도를 `tools/v2/tm.py` 의 `ll_to_xz` 로 바꿔 정하고, 정한 까닭을 한 줄씩 적는다. 회전교차로가 판 안에 없으면 없다고 적는다.
2. **세 장 찍기**(헤드리스 Chromium, 지시서 3c·4a 와 같은 방법, 1600×1000, 로딩 뒤 3초):
   - 2D: `tmp/v2/marks.png` 에서 가운데 둘레 265m 폭을 잘라 낸다.
   - 카카오맵: 같은 가운데, 같은 폭(README 「결과를 검수할 때」 3 의 방법).
   - 3D 낮: `?v=2&view=x,z,260,50,-30&t=13:00&dow=0&weather=clear`.
   한 자리마다 세 장을 가로로 붙인 그림 하나(`cmp-<이름>.png`)를 만든다.
3. **밤**: 합정, 홍대입구역, 서교동사거리(−70, −130) 세 곳은 3D 밤(`t=22:00`)도 한 장씩 찍는다.
4. **한 장에 모으기**: 열 곳의 3D 낮 화면을 5×2 로 줄여 붙인 `ten-3d.png` 와, 열 곳의 2D·카카오맵을 붙인 `ten-2d.png` 를 만든다. 지오에게 보낼 그림이다.

## 판정 (자리마다 한 줄)

`docs/redraw.md` 7절 「확인하는 것」(큰길이 이어지는 모양, 교차로 자리와 갈래 수, 큰길 폭의 비례, 건물 블록 모양, 광장·보행 거리의 자리, 한강·철도)에 비춰 **같은 곳으로 보이는가 / 서비스 거리(약 150~250m 폭)에서 거슬리는 것이 있는가**를 적는다. 거슬리는 것은 그림에서 본 뒤 자료에 점을 찍어 확인하고, 원인을 이미 알려진 것(README 「4a 에서 나온 것」과 4b 줄의 남긴 것: 합정·신촌 넓은 찻길, 성산로 없음, 고가가 평평함, 나들목 엉킴, 부채꼴, 출구가 찻길 위)인지 새것인지 가려 적는다. 새것만 자세히 적는다.
