# 계획 세우기 안내 (루프가 목록이 비었을 때 읽는다)

## 이 단계의 목표 (단계 S1, 지오 2026-11-26)
마포 전역(`tools/v2/areas/mapo-all.json`)의 정적 지도를 **차로와 노면 표시까지** 완성해 지오에게 화면 주소 하나로 보인다. 그때까지는 지오에게 묻지 않고 이 루프로 이어 간다. 차·사람은 이 단계에 넣지 않는다.

단계가 끝났다고 판단하는 조건(모두): ① 전역 지도가 칸으로 나뉘어 화면 주소 하나로 열린다(홍대 일대의 `?tiles=1` 과 같은 길) ② `docs/redraw-orders/s1-checklist.md` 의 1~18번이 처리됐거나, 처리하지 않은 것은 까닭이 적혀 있다 ③ 큰길 사진 대조(`tools/v2/road_audit.py`)를 새 범위 전체에 돌렸고 검수 페이지가 있다 ④ 가까운 배율·중간 배율·전체 보기·모바일 캡처를 실제 GPU 로 찍어 두었다(`tmp/connect/gpushot.mjs`). 그러면 일감을 쓰지 말고 `tmp/loop/stage-done.md` 에 주소(완전한 `http://localhost:…` 링크)와 무엇이 됐고 무엇이 남았는지 한 단락을 쓴다.

## 일감을 쓰는 법
- 한 번에 **일감 하나**만 쓴다. 한 일감은 한 주제(자료 하나, 화면 하나, 검사 하나). 앞 일감의 결과(`tmp/loop/<id>/`, `git log`, `loop.log`)를 보고 다음 것을 고른다. 이미 된 것을 다시 시키지 않는다.
- 폴더 `docs/redraw-orders/queue/<id>/` 에 `task.env`, `brief.md`, `check.sh` 를 쓴다. 모양은 `queue/s1-outline/` 을 본뜬다. `check.sh` 는 구현자가 고칠 수 없는 통과 기준이다: 목표 수치와 「나빠지면 안 되는 것」(다른 구역 자료·`src/sim` 그대로, s1-bake 검사)을 함께 건다. 처음 재는 칸에는 문턱을 걸지 말고 값을 적게만 한다.
- `brief.md` 는 12,000바이트 안쪽. 지오의 원문 한두 줄, 읽을 곳(파일과 줄 범위, `docs/code-map.md`), 할 일, 문턱과 재는 명령, 「하지 않는 것」, 「답의 꼴」(줄 수 상한). `mapo/CLAUDE.md` 「낭비 없이 일하는 법」에 있는 규칙은 다시 적지 않는다.
- 모델과 에포트(전역 `~/.claude/CLAUDE.md` 표): 판단과 예외가 많은 구현은 `IMPL=opus` + `high`, 시험이 정답을 정해 주는 구현은 `sonnet` + `medium`, 단순 수집은 `haiku` + `low`. **검수는 언제나 `REVIEW=sol`, `REVIEW_EFFORT=medium`**(지오: Codex 는 검수에만).
- `SHOTS` 에는 검수자가 직접 열어 볼 그림 경로를 적고, 그 그림은 구현이 만들게 한다(화면이면 `node tmp/connect/gpushot.mjs <폴더> <이름=주소>`, 자료면 위에서 본 400m 그림).
- 화면을 바꾸는 일감의 문턱에는 폭 60~200m, 600~1,500m, 전체 보기, 모바일(390×844)을 모두 넣는다. 5198 은 정적 서버라 개발 화면은 Vite 개발 서버를 다른 포트(5199 등)로 띄워 본다.

## 순서의 기준 (바꿀 까닭이 있으면 바꾼다)
1. 윤곽·자료 확정(`s1-outline`) → 2. 칸으로 나누고 화면 주소 만들기(`pack_district_tiles.py`·`pack_district_tile_meshes.mjs`·`district-tiles.ts`, 홍대 I2 와 같은 길, `docs/area-recipe.md` 「I2」) → 3. 물 없는 지도 조각 두 곳 메우기 → 4. 새 범위 항공사진 받기(`survey_roof_tiles.mts --area`) → 5. 큰길 사진 대조와 검수 페이지(`road_audit.py --area mapo-all`), 차로 수·폭·노면 표시가 틀린 길을 길마다 고치기(번호·좌표 예외 금지, 규칙으로) → 6. 차로 자료(A2)가 없는 길(연세로·명물길·잔다리로 등)의 차선을 노면선(B2) 등 원자료로 채울 수 있는지 조사 후 구현 → 7. 체크리스트 나머지와 캡처.
- 건물은 큰길가와 유동인구 많은 쪽(홍대 관광특구, 신촌, 합정, 공덕)이 중요하다(지오).

## 하지 않는 것
- 차·사람·버스·신호 재생, `pnpm bake`, 전체 `pnpm test`, `git stash`·`reset --hard`·강제 푸시, 미리보기 도구·claude-in-chrome. 소리를 내지 않는다.
- 구운 자료(`public/data/v2/mapo-all*`)는 `.gitignore` 로 묶여 있다. 단계가 승인되면 마스터가 한 번에 올린다. 일감이 이 규칙을 풀지 않는다.
- 이 안내 파일과 기존 일감 폴더, `tools/sol/` 를 고치지 않는다. 일감 목록에는 줄을 더하기만 한다.
