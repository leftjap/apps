# s1-deck-mask: 고가·다리 아래 도로의 도색이 상판 위로 비치는 것을 가린다

지오(2026-11-25): 「건물은 지금처럼 대충 그려놔도 상관없음 … 근데 도로는 조금 더 디테일이 있으면 좋겠어.」 판정 기준은 「서비스 배율에서 눈에 거슬리는가」다. 지금 전역 지도는 높이가 다른 길을 모두 땅 높이로 그려서, 고가차도와 다리 위에 아래 도로의 차선·중앙선·정지선이 함께 깔려 격자처럼 엉킨다(검수 목록 16번, `s1-review` 의 차선 틀림 13·15·16). 이 일감은 **상판 아래 도로의 도색만 가린다.** 상판을 공중으로 올리는 일(조사의 후보 2)은 하지 않는다.

## 이미 알아낸 것 (다시 조사하지 않는다)

- 앞 일감 `s1-decks` 가 규칙과 수치를 이미 냈다. 요약은 `tmp/loop/s1-decks/summary.md`(25줄), 측정 코드는 `tmp/loop/s1-decks/measure_decks.py`(488줄)에 **돌아가는 상태로** 있다. 규칙을 다시 유도하지 말고 이 코드를 옮겨 쓴다.
  - 쓸 함수: `hd_lines` 163-205(A2·B2 를 평면으로 투영하고 A2 정점 Z 를 함께 돌려준다), `elevation` 206-211, `crossing_pairs` 212-223, `tangent` 224-231, `grade_crossings` 232-259(교차각·Z차·상판 추종 길이로 위/아래 쌍을 고른다), `candidate_impacts` 357-410(상판 선별과 B2 참조로 아래 도색을 세는 자리), `Layer` 125-145, `faces`·`polygons` 58-67.
  - 확인된 것: **A2 원본 좌표의 Z 가 층을 가른다.** 사진의 층 순서와 성산2교 43/43쌍·마포구청역 58/58쌍이 일치했다(Z차 12.2~13.1m). 「상판 면 안에 든다」만으로는 못 가른다(사진상 위쪽이 24%·30%뿐). 속성에는 층·표고 칸이 없다.
  - 선별 임계값(조사에 쓴 값): 도로교·고가차도 면 안, 교차각 ≥35°, A2 Z차 ≥3m, 위 링크가 교차점을 품고 상판을 20m 이상 따름(20m 보다 짧은 링크는 전 길이). 전역에서 상판 69면(도로교 30·고가차도 39), 265,583㎡. 그 안의 노면선 87,999m 가운데 위 47,258m·아래 12,030m 가 B2 좌우 참조로 한 층에 붙고 나머지 28,711m 는 참조가 갈려 판정이 없다.
- **흰 선은 A 보기의 도색 면에서 나온다.** `survey_road_paint.py` 222행이 `white = surface([... data['paint'] ... color==2 ...])` 로 흰 도색 면을 받아 `white.fine`·`white.stops` 로 쪼갠다. 화면은 `src/aerial/yanghwa-terrain.ts` 104-108행에서 색 2 자리에 `white.fine`·`white.stops` 를 대신 그린다. 따라서 **A 보기의 `paint` 를 가리고 `survey_road_paint.py` 를 다시 돌리면 흰 선도 따라 가려진다.** 황색(색 1)은 A 보기 면이 그대로 화면에 간다.
- **`lines` 는 화면이 쓰지 않는다**(칸 모드). 검수 그림과 차 쪽이 쓰므로 **고치지 않는다.** 검수 그림은 `road_audit_raster.py` 155행이 `a['paint']` 를 쓰므로 저절로 화면과 같아진다.
- 계획 세우기가 커밋 832d4ac9 의 구운 자료에서 직접 잰 값이다. 상판(도로교·고가차도) 233면 602,508㎡. 거기 겹친 **보이는 도색 20,460㎡**(황색 3,663 · 흰 선 세부 14,986 · 정지선 109 · 빗금 1,220 · 화살표 480), 상판 밖 85,831㎡. A 보기 흰 도색 원본(색 2)은 상판 안 15,096㎡. 노면선 19,850행 857,081m(상판 안 173,127m), 횡단보도 2,565행(상판에 닿는 것 49).
- 창 안 상판 도색: 성산2교 `-638.17,-1535.73` 폭 200m 232㎡·폭 60m 39㎡, 마포구청역 `-1394.21,-1364.79` 폭 200m 273㎡. 사진은 `tmp/loop/s1-decks/shots/d-02-photo.jpg`·`d-03-photo.jpg` 에 있다(고가가 아래 접근로를 가린 모습).

## 할 일

1. **새 파일 `tools/v2/deck_mask.py`** (맨 위에 무엇을 하는 파일인지 한 줄 주석). 구역을 받아 세 가지를 낸다: 선별된 상판 면, 「아래」 A2 링크 id 집합, 「위」 A2 링크 id 집합. 선별은 위의 임계값 그대로. 층 판정은 쌍에 든 링크로 끝내지 말고, **선별된 상판마다 그 면과 겹치는 A2 링크를 모두 훑어 위 링크의 그 자리 Z 보다 2m 이상 낮은 링크를 「아래」로 넣는다**(그래서 12,030m 보다 늘어난다. 조사의 후보 1 은 쌍에 든 링크만 세어 아래를 적게 잡았다).
2. **`hapjeong_hd_a.py` 에서 아래 도색을 뺀다.** 「아래」 판정은 B2 선의 `l_linkid`·`r_linkid` 가 **둘 다 아래**일 때만 내린다(한쪽만이거나 비면 그대로 둔다). 폭 규칙으로 넣은 선(`origin == 'width-rule'`, 213행)은 그 선이 딸린 축이 아래일 때 뺀다. **상판 안 구간만 잘라 낸다**(선을 통째로 버리면 상판 밖 도색이 줄어 검사가 떨어진다). `result['lines']`·`crossings`·`crossingAudit`·`floor` 는 그대로 둔다.
3. **빗금과 화살표도 같은 판정으로 상판 안 조각만 뺀다.** 빗금은 `survey_road_paint.py` 가 B2 501·531 로 만들고, 화살표는 원본 면의 `linkid` 로 차로를 찾는다(두 자리 모두 위에 적었다). 1번 모듈을 다시 부르지 않으려면 판정 결과를 A 보기 자료의 새 열쇠(예: `deckMask`)로 넘긴다. 어느 쪽을 골랐는지 답에 적는다.
4. **참조가 없거나 갈리는 선은 가리지 않는다.** 선별된 상판 안에 그렇게 남은 노면선 길이와, 남은 빗금·화살표 면적을 재서 `measure.md` 에 적는다(다음 일감의 근거다).
5. **다시 굽기 전에** 고치기 전 화면을 찍는다. 1번 모듈만 돌려 「아래」로 가려질 도색을 구하고, **60m 창에서 가려지는 도색이 가장 많은 자리**를 골라(성산2교·마포구청역 중심에서 300m 이상 떨어진 곳) `tmp/loop/s1-deck-mask/spots.tsv` 에 머리줄 없이 한 줄 쓴다: `deck-c<탭>x<탭>z<탭>그 창에서 가려지는 도색㎡`(쉼표 없는 숫자). 그다음 여덟 장을 `tmp/loop/s1-deck-mask/before/` 에 찍는다(이름과 주소는 아래 「문턱」과 같아야 한다).
6. **다시 굽는다**(순서 그대로, 약 8분. 배경으로 돌리고 기록을 `tmp/loop/s1-deck-mask/bake.log` 에 남긴다).

## 하지 않는 것

- **지하차도**(열린 진입부와 덮인 몸통을 가를 자료가 없다. 조사에서 확인했다). 상판을 공중으로 올리기(후보 2). 차·사람·버스·신호 쪽 자료·코드·재생, `pnpm bake`, 전체 `pnpm test`.
- 횡단보도 손대기(상판에 닿는 49개는 그대로 둔다). `lines` 고치기. `src` 고치기(화면 코드는 이미 준비돼 있다. 고쳐야 할 까닭을 찾으면 고치지 말고 답에 적는다).
- 좌표·구간 번호·상판 이름·링크 id 로 예외 두기. 보도교까지 가리기. 바닥·건물 다시 굽기. 다른 구역 자료·설정 고치기.
- 앞 일감의 검사 파일(`queue/s1-*/`)과 이 일감의 `check.sh`·`mask.py` 고치기.
- **문턱을 못 넘으면 넘은 척하지 않는다. 앞 결과를 섞거나 수치 파일을 손으로 쓰지 않는다.** 검사가 두 번 연속 같은 자리에서 떨어지면 멈추고 막힌 자리를 답에 적는다.
- 미리보기 도구와 `claude-in-chrome`(지오에게 승인 창을 띄워 세션을 멈춘다). 소리를 내지 않는다.
