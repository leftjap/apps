# words.json 의 출처와 라이선스

`words.json` 은 한국어 맞춤법 사전 hunspell-dict-ko 0.7.92 의 `ko.dic` 에서 명사와 단위 명사(품사 표시 9, 10, 24, 25)만 뽑고, 이 게임의 점수표에 있는 단어를 더한 목록이다. 만드는 스크립트는 `probe/build-words.mjs` 다.

이 단어 목록(`words.json`)과 이 목록을 그대로 담은 `local.html` 안의 단어 목록 부분은 같은 조건(CC BY-SA 4.0)으로 다시 쓸 수 있다.
