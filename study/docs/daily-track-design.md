# daily 트랙 설계 (파일럿)

> 2026-09-11 착수. 근거 정본 = `docs/speaking-baseline.md` (실측). 소스 뱅크 = `docs/pattern233-bank.md`,
> `seeds/en-moduyeongeo-*.json`, `docs/core100-curriculum.md`.
> **코어100 존속 여부는 이 파일럿을 본 뒤 판단한다** (사용자 지시 2026-09-11). 그때까지 날짜는 임시다.

## 1. 왜 새 트랙인가 (진단)

`speaking-baseline.md` 실측 두 가지가 근거다.

1. **밴드 이탈** — 사용자 실제 산출 평균 3.7단어(최대 5). 코어100 본문 100문장 중 ≤5단어 **0개**.
2. **골격 미접속** — 사용자가 소유한 골격 4종이 en 코퍼스 1,394건에 0~1건만 출현.
   앱은 사용자가 쓸 수 있는 토대 위에 확장을 쌓은 적이 없다.

②가 ①보다 중요하다. 길이만 줄이면 짧고 낯선 문장이 될 뿐이다.

## 2. 설계 규칙 (기계 검증 가능한 것만)

| ID | 규칙 | 검증 |
|---|---|---|
| **D-1** | 카드 `sentence` 는 **3~6단어**. | `scripts/daily-metrics.mjs` |
| **D-2** | 세션당 **신규 골격 정확히 1개**. 나머지 카드는 기보유 골격 또는 앞선 세션에서 도입한 골격. | 동상 |
| **D-3** | 전 세션 카드 중 **기보유·기도입 골격 비율 ≥70%**. | 동상 |
| **D-4** | `drills` 전부 **3~7단어**. 드릴은 확장 연습이지 새 벽이 아니다. | 동상 |
| **D-5** | 카드마다 `miniDialogue` 2~4턴. 상대 대사가 **실제 영어 cue** 가 된다. | 동상 |
| **D-6** | 한 세션 4장이 **하나의 대화**로 이어진다 — 카드 고립 금지. | 사람 판단 |
| **D-7** | 모든 개인 사실은 **출처 대장(§4)에 등재된 것만**. 미등재 사실 생성 금지. | 사람 판단 |
| **D-8** | `chain.target` 은 base 에서 8~11단어로 확장. 생산이 아니라 **듣기·확장** 자리다. | 기존 `validate-seed.mjs` |

기존 게이트(`EXPL_REQUIRED` 10필드 · `phonetic_kr`↔`chunks` 정합 · `drills≥4` · 첫 단어 3종 ·
`chain` 의무 · 어려운 어휘 차단)는 그대로 적용한다. `daily` 를 `isScenelessTrack` 에 추가만 했다.

## 3. 골격 도입 순서 (i+1)

기보유: `I'm (a little) + 형용사` / `I went to + 장소` / `I had + 명사` / `I'm gonna + 동사원형`
\+ 고정 청크 `Nothing much.` `How about you?`

| 세션 | 신규 골격 1개 | 선정 근거 |
|---|---|---|
| 1 | `It was ~.` | 사건만 말하고 **평가를 못 붙인다**. `I went to the gym.` 뒤에 붙일 한마디가 없다 |
| 2 | `My wife ~s.` (3인칭 -s) | **실제 붕괴 지점**. baseline 기록 `Because my wife... go... to work...` |
| 3 | `How was ~?` | 되묻기 수단이 `How about you?` 하나뿐이라 대화가 한 턴에 끝난다 |
| 4 | `I didn't ~.` | 18표현에 **부정문 0건** |
| 5 | `I have to ~.` | 일기의 "~해야 한다" 를 옮길 수단이 없다 |

각 골격은 도입 세션 이후 다음 세션들의 카드·드릴에서 재등장한다(D-3).

## 4. 개인 사실 출처 대장 (D-7)

**이 목록에 없는 사실은 문장에 넣지 않았다.** 일기 접근이 가능한 로컬 세션에서 이 대장을 일기로
교체·확장하는 것이 다음 단계다.

| ID | 사실 | 출처 | 등급 |
|---|---|---|---|
| F1 | 아내가 있다 / 아내가 출근한다 | 사용자 발화 `Because my wife... go... to work...` | 1차 |
| F2 | 출근한다 | 사용자 발화 `I went to work.` | 1차 |
| F3 | 헬스장에 간다 / 운동한다 | 사용자 발화 `I went to the gym.` `I'm gonna work out.` | 1차 |
| F4 | 맥주를 마신다 | 사용자 발화 `I had a beer.` | 1차 |
| F5 | 커피를 마신다 | 사용자 발화 `I had coffee.` | 1차 |
| F6 | 점심을 먹는다 | 사용자 발화 `I had lunch.` | 1차 |
| F7 | 집에 있는다 | 사용자 발화 `I'm gonna stay home.` | 1차 |
| F8 | 자러 간다 | 사용자 발화 `I'm gonna go to bed.` | 1차 |
| F9 | 쉰다 | 사용자 발화 `I'm going to rest.` | 1차 |
| F10 | 술 마시러 간다 | 사용자 발화 `I'm gonna have a drink.` | 1차 |
| F11 | 피곤·바쁨·배고픔 상태를 말한다 | 사용자 발화 `I'm a little tired/busy/hungry.` | 1차 |
| F12 | 고양이를 기른다 | 기존 시드 48건 (`seeds/en-core100-*.json` 드릴) | **2차** |

**1차** = 사용자가 직접 말한 것. **2차** = 이전 세션이 시드에 쓴 개인화로, 사용자가 학습 중이라
노출은 됐으나 본인 확인은 안 된 것. 2차는 드릴에서만 쓰고 카드 본문에는 쓰지 않았다.

**미검증이라 쓰지 않은 것**: 기상·출근 시각, 직업, 사는 곳, 여행 계획, 아내의 직업·일과,
자녀 유무, 취미(운동 외), 식단 세부.

## 5. 파일럿 범위

5세션 × 4장 = 20장. 파일 `seeds/en-daily-2026-09-19.json` ~ `2026-09-23.json`.

**날짜는 임시다.** `date` 는 달력이 아니라 세션 순서이고(spec §5-1), 코어100 미완료 묶음이
앞에 있으면 로더가 그것부터 연다. 코어100 판단 후 재배정한다. **판단 전 Supabase 적재 금지.**

## 7. 검증 결과 (2026-09-11)

### 기계 게이트

```
node scripts/validate-seed.mjs --payload seeds/en-daily-2026-09-*.json   → 5/5 OK
node scripts/daily-metrics.mjs                                           → D-1~D-5·D-7 OK
pnpm test                                                                → 80파일 1567건 통과
```

| 지표 | 값 |
|---|--:|
| 카드 | 20장 (5세션 × 4) |
| `sentence` 평균 | **4.3단어** (범위 3–6) |
| `drills` 평균 | 4.7단어 (범위 3–7, n=100) |
| 재사용 비율 | **75%** (하한 70%) |
| 세션당 신규 골격 | 1 / 1 / 1 / 1 / 1 |

### 골격 접속률 (본 트랙의 핵심 지표)

문장 + 드릴 + 미니대화 전체에서 사용자 기보유 골격이 나타나는 비율.

| 트랙 | 표본 | 기보유 골격 포함 |
|---|--:|--:|
| **daily (파일럿)** | 181건 | **52%** |
| core100 | 1,047건 | 4% |

`I went to +장소` 는 core100 전체 1,047건에 **0건**, daily 파일럿엔 13건이다.

### 남은 경고 1건 (고치지 않음, 사유 기재)

`validate-seed` 가 세션 1·4·5 에서 **"기본동사 비중 낮음(2/4 < 60%)"** 경고를 낸다.

원인은 콘텐츠가 아니라 게이트의 어휘 목록이다. `BASIC_VERBS` 는 원형·과거형 위주라
`goes`·`works`·`stay`·`going`·`gonna`·`didn't` 가 빠져 있다. 그런데 daily 트랙이 가르치는 것이
정확히 **3인칭 -s · be gonna · 과거 부정** 이라, 이 트랙에서는 구조적으로 항상 걸린다.

`BASIC_VERBS` 는 RealClass 마이닝의 구동사 선택을 막으려고 만든 공용 집합이라, 이 트랙 편의로
넓히면 다른 트랙 판정이 함께 흔들린다. **경고로 남기고 목록은 건드리지 않았다.**
daily 트랙을 채택하면 그때 (a) 목록 확장 (b) daily 한정 면제 중 무엇을 할지 정한다.
