# Study 앱 — 영어 코어 100문장 커리큘럼

> 확정 2026-08-26. 이 100문장이 **en 신규 학습의 유일 대상**이다 (모두영어·RealClass 트랙은 중단, 기존 복습 카드는 soft-delete 보관).
> 선정 근거·기준은 §1, 문장 목록은 §2. 시드 생성 규칙은 [lesson-explanation-guide-en.md](./lesson-explanation-guide-en.md) §6.3 (track=`core100` 면제 경로).

## 1. 선정 기준

**학습자 프로필** (사용자 자기 보고): 1976년생 · 대학생 때 토익 700 · 이후 영어 사용 없음 · 독해 우세 · 듣기 약함 · 말문 막힘.
→ 목표 수준 = **독해 B1 전후, 말하기·듣기 A2 후반→B1**. 새 문법 주입이 아니라 **이미 읽을 수 있는 문법의 발화 절차화**가 목적.

**1차 목표**: 여행영어 + 넷플릭스(자막 의존도 낮추기).

| 기준 | 내용 |
|---|---|
| 형식 | 전 문장 6~12단어 **완결 문장** (평균 8.4단어). 짧은 청크는 버리지 않고 완결 문장 안에 담는다 |
| 근거 | 앱 정본이 짧은 반응 단독 카드를 금지하고 최소 1개 절을 요구 (guide-en §6.3 "맨 구문 금지") |
| 난이도 | 읽으면 이해되지만 말로는 안 나오는 밴드. 직역 조립 가능한 초급 단골 문장 배제 |
| 중복 | 기학습 215문장(기존 시드)과 기계 대조 — 완전 중복 0 |
| 회상 적합 | 한글 프롬프트 → 자연스러운 영어 답이 사실상 하나로 수렴 (Rung 3 채점용) |
| 빈도 | 영화 자막 코퍼스(playphrase.me) 실측은 **보조 지표**로만 사용. 정확 문자열 검색이 단문에 유리해 채택 기준으로 쓰면 단문 편향 발생 |

**블록 구성**: 1–30 말문·대화 운영 / 31–50 일상 설명·서사 / 51–80 여행 (질문·답변 짝 + 문제 해결) / 81–100 미드 듣기·구어 문형.

## 3. 운영

- **시드 분할**: 1세션 = 5~7문장, 번호 순서대로 진행 (1–30 → 31–50 → 51–80 → 81–100). 총 16~20세션.
- **적재 방식 (2026-09-03 사용자 확정)**: 데몬 없이 **일괄 적재**. 시드 파일 하나 = 세션 하나이고, `date` 는 달력이 아니라 **세션 순서**다(하루씩 증가, 7~12 는 09-04 부터). 앱 로더가 오늘까지의 미완료 중 가장 오래된 날짜 묶음 하나만 열고, 오늘까지의 묶음을 다 끝냈으면 다음 날짜 묶음을 당겨 연다(`src/pages/cardLoader.js`). 홈 신규 카운트는 그 묶음의 표현 수다. 재적재 게이트는 id 기준이라 완료된 카드는 날짜와 무관하게 차단되고(`scripts/seed-supabase.mjs`), 시드 적재 시 14일 방치 자동 삭제는 폐지됐다(미리 넣은 묶음을 지우던 사고). **코어100용 세션 생성 자동화(데몬)는 신설하지 않는다.** 아직 날짜가 안 된 묶음은 파일을 고쳐 다시 올릴 수 있다(미완료 행이라 게이트 통과).
- **트랙 태그**: 시드 payload `track: "core100"` — scene 카드 없는 표현 전용 세션 (validate-seed 면제 경로, moduyeongeo 와 동일 취급).
- **chain 의무** (2026-08-28): 표현 카드마다 `explanation.chain{target,chunks,ko}` 를 반드시 넣는다. scene 이 없는 트랙에서는 체이닝이 **유일한 청각 확장 축**이라, 빠지면 세션 화면에서 블록이 통째로 사라지고 연습 문장이 11→8 로 준다. 최초 시드(1~6번)가 chain 없이 들어가 실제로 그 회귀가 났고(사용자 보고 2026-08-28), 게이트를 선택→의무로 승격해 재발을 막았다. 스키마·작성 규칙은 [explanation-schema.md §chain](./explanation-schema.md).
- **응용 드릴은 핵심 표현을 재사용한다**: `key` 좌변 표현이 드릴에 한 번도 안 나오면 응용 행 밑줄(시안 §4.4)이 0개가 된다. 게이트가 경고로 알린다 — 패러프레이즈만 나열하지 말고 표현을 다시 쓰는 변주를 섞을 것.
- **드릴 개수는 목표가 아니라 결과** (2026-08-28): 표현마다 콜로케이션 폭이 다르므로 개수를 고정하지 않는다 — 정본은 [explanation-schema.md §drills](./explanation-schema.md) 「4개 이상, 상한 없음, 개수는 결과이지 목표가 아니다(사용자 지시 '필요한 만큼')」. 최초 시드(1~6번)는 `frequency` 가 7~10으로 갈리는데 **6장 전부 정확히 5개**였다 — 가장 넓은 `could you say that again`(freq 10)이 가장 좁은 `put it into words`(freq 7)와 같은 양이라, 문서가 상한을 폐지하며 적은 이유("활용도 높은 표현의 연습을 막았음")가 그대로 재발했다. 재작성 후 8·8·7·7·5·7 (드릴 30→42). `frequency` 는 **빈도**일 뿐 콜로케이션 폭이 아니므로 기계 규칙으로 삼지 않는다 — 저작 시 표현별로 판단한다.
- **기존 카드**: 기존 en 복습 카드 98장은 soft-delete(`explanation._deleted=true`) 로 보관 — 서버 데이터는 남고 복습 큐에서만 제외. 되살리려면 플래그 해제.
- **모두영어 데몬 중지**: launchd `com.gio.study-advance-check` 를 2026-08-26 bootout. 미완료 편을 정리하면 이 데몬이 다음 편을 자동 재적재해 전환이 되돌아간다(실측). 상세는 `../CLAUDE.md` 자동화 박제.

- **난이도 판정의 정본은 복습 자기평가다 — 발음 점수가 아니다** (2026-08-29). 앞서 발음 점수로

  애초에 **낭독 발음 정확도**이지 이 커리큘럼이 훈련하는 **한글→영어 인출**이 아니다.
  ("문장 이해하고 발음 따라하는 건 문제없는데 한글로 떠올릴 수 있는지가 애매하다" — 사용자 2026-08-29.)
  "저점은 무음 캡처라 무효"라던 기록은 **틀린 이유로 맞는 결론**이었다. 순수 감쇠는 점수와 무관하지만
  (정상 발화를 rms 0.0007 까지 줄여도 98점), 실제 저점의 원인은 **SNR 저하**이고 그때 rms 도 함께
  내려간다. 즉 rms 는 원인의 지표이지 원인 자체가 아니고, 단독 판별자도 못 된다(0.0364 가 정상과
  비정상 양쪽에 걸친다). 판별자는 음소 원시 점수다 — 상세는 `services/coverageJudge.js judgeRecording`.
- **인출 실측 (유일한 정본 데이터 — 단 코어100 자신의 것이 아니다)**: `study_review_queue.last_result`
  가 남은 en 카드 14장 — **O 2 / △ 8 / X 4**. ⚠ 이 14장은 전부 soft-delete 된 **모두영어 트랙**
  문장(3~6단어)이고, 코어100 카드의 인출 실측은 2026-08-29 현재 **0건**이다 (2026-08-29 재감사 명시).
  즉 아래는 '지오의 인출이 어디서 막히는가'의 증거이지 코어100 문장 자체의 난이도 실측이 아니다 —
  코어100 첫 실측은 오늘 복습부터 쌓인다. 그 14장에서 성패와 가장 눈에 띄게 동행한 축은 길이가 아니라
  **한글에서 영어를 역산할 수 있는가**였다 (△ 8장은 중간지대라 이 이분법이 전부를 가르진 않는다):
  · O 2장 = 직역 가능 — `Are you hungry?` · `I'm sorry I'm late.`
  · X 4장 = 전부 관용·구동사 — `I'm seeing someone.` · `I'm on my way.` · `I'll be there in a minute.` · `Can you come over?`
  학습자 프로필의 약점(구동사·관용구)과 정확히 겹친다.
- **그래서 문장 교체·난이도순 재정렬은 하지 않는다.** 어휘는 전부 고빈도 기능어·기본동사라 독해 B1
  에 병목이 아니고, 인출이 어려운 것은 §1 이 「직역 조립 가능한 초급 단골 문장 배제」로 **의도한 결과**
  다. 목표(넷플릭스 자막 의존 낮추기·여행 말하기)와 약점(구동사·관용구)에 정렬돼 있으므로 외울 값을
  한다 — 관용 표현은 한글에서 역산이 안 되니 외우는 것 외에 길이 없고, 그게 곧 미드 듣기의 재료다.
- **다만 §1 의 두 기준은 관용 표현에서 상충한다** — 「직역 조립 가능 배제」(=관용적이어야)와
  「한글 프롬프트 → 답이 하나로 수렴」(=역산 가능해야)이 같은 문장에서 동시에 성립하기 어렵다.
  위 X 4장이 정확히 그 충돌 지점이다. **해법은 문장이 아니라 프롬프트다**: 7~100 저작 시 한글
  프롬프트를 **수렴형**으로 쓴다 — 자연스러운 의역("지금 갈게")이 아니라 그 표현을 유도하는 표현
  ("지금 가는 중이야" → on my way). 프롬프트가 발산하면 아무리 좋은 문장도 인출 훈련이 안 된다.
- **외울 가치 = 핵심 표현의 코퍼스 빈도** (2026-08-29 실측). 1~30 의 핵심 표현 23개를 YouGlish
