# 학습자 발화 베이스라인 (en)

> 세션 콘텐츠의 **산출 난이도 상한**을 정하는 정본. 새 시드를 만들기 전에 이 문서를 먼저 본다.
> 읽기·이해 난이도가 아니라 **즉석에서 조립해 입으로 나오는 난이도**가 기준이다.

## 2026-09-11 측정

**방법**: ChatGPT 음성 모드 자유 대화 (앱 밖). 힌트·대본 없음.
**판정**: 말하기 **A1**. (2026-08-26 코어100 커리큘럼이 가정한 "말하기 A2 후반→B1" 은 과대 추정이었음.)

**관찰**
- 읽기·이해는 즉석 말하기보다 상당히 낫다. 따라 말하기는 잘 된다.
- 문장을 **처음부터 조립하는 것**만 초급이다. 즉 문제는 지식이 아니라 인출이다.

### 스스로 산출한 표현 (힌트 없이 나온 것)

```
I'm okay.                    I went to the gym.        I'm going to rest.
I'm fine.                    I went to work.           I'm going to work out.
I'm a little tired.          I had a beer.             I'm gonna work out.
I'm a little busy.           I had coffee.             I'm gonna have a drink.
I'm a little hungry.         I had lunch.              I'm gonna stay home.
Nothing much.                                          I'm gonna go to bed.
How about you?
```

**골격 4종뿐**: `I'm + 형용사` / `I went to + 장소` / `I had + 명사` / `I'm gonna + 동사`.

### 무너진 지점

```
Because my wife... go... to work...
And... we go...
```

→ 접속사로 절을 **두 개 잇는 순간** 붕괴. 시제·주어 일치도 같이 무너진다.
→ 현재 안정 산출 단위는 **단문 1개**다.

**결정적 수치**
- 코어100 본문 100문장 중 **5단어 이하 = 0개 (0%)**. 모두영어는 **80%**.
- 기존 en 시드 전체(본문+드릴 **1,376문장**)를 대조한 결과, 위 18개 산출 표현과
  일치하는 문장은 **0건**. 앱이 사용자의 실제 산출 밴드를 한 번도 다룬 적이 없다.

**해석**: "모두영어는 재미있었고 코어100은 쓸 자신이 없었다"는 사용자 소감은 취향 차이가
아니라 **길이 차이**로 설명된다. 재미의 원인을 개인화로 단정하기 전에 길이를 먼저 의심할 것.

**당면 상한**: 신규 생산 대상 문장은 **3~6단어 단문**. 절 2개 연결은 생산 대상에서 제외
(이해·듣기용으로만 노출). 이 상한은 재측정 전까지 유지한다.

## 미검증 항목 (인용 금지)

아래는 외부(ChatGPT) 제안에 포함됐으나 **repo·코드에서 확인되지 않았다**. 근거로 쓰지 않는다.

1. **"모두영어 인출 성공/실패 기록"** — 앱은 인출 성공/실패를 기록하지 않는다.
   `sessionReviewV2` 의 자동 채점은 **Azure 발음 점수** → SRS 판정 변환(`deriveKind`:
   ≥80 got / ≥60 hmm / 그 외 no / 미측정 hmm)이다. 즉 저장된 O/△/X 는 **발음 점수이지
   인출 여부가 아니다**. 게다가 진짜 회상은 Rung 3(interval ≥ 21)에서만 일어난다(spec §8-2-0).
   → "이 표현은 인출에 실패했다" 는 현재 데이터로 말할 수 없다. **인출 성공/실패를 실제로
   기록하는 필드가 없다는 것 자체가 최우선 결함이다.**
2. **`I'm seeing someone`** — "과거 모두영어 트랙에서 확인된 문장"이라고 제시됐으나
   `seeds/en-moduyeongeo-*.json` 6개 파일 어디에도 없다. 출처 불명.
