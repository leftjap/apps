1목적과 설계 원칙

이 앱의 단 하나의 목적: 사용자가 오늘 네 가지 활동(독서·글쓰기·어학·운동)의 도구를 실제로 열게 만드는 것. 모든 기록은 각 도구에서 자동으로 측정되어 넘어온다 — 대시보드에는 수동 입력·체크 UI가 없다.

  1. 시각적 위계는 단 하나의 흐름 — ① 시간이 가고 있다(시계·타임라인) → ② 오늘의 원이 덜 닫혔다(하루 고리) → ③ 각 활동의 재개 지점(행) → ④ 깰 수 있는 기록(펼침). 이 순서 밖의 요소를 추가하지 않는다.
  2. 색은 한 곳에만 — 화면 전체가 웜 그레이 모노톤이고, 포인트색(오렌지)은 "시간·지금 할 일·경신 가능 기록"에만 쓴다. 포인트색이 세 군데 이상 동시에 강조되면 잘못된 것이다.
  3. 동기 장치는 세 가지 — 유한한 하루(타임라인), 미완성의 원(열린 고리, 자이가르닉 효과), 깨고 싶은 기록(goal-gradient: 가까운 목표일수록 동기 상승). 이외의 게이미피케이션(포인트·레벨·배지)은 도입하지 않는다.
  4. 모든 문장은 구체적 사실 — "잘하고 있어요" 같은 빈 격려 금지. 책 제목·쪽수·날짜·분량처럼 DB에서 온 구체값만 말한다.

5컴포넌트 명세

5-1. 시계 블록

  • HH:MM 68px, 콜론은 #C9BCA1. 초는 바로 옆 베이스라인에 17px 포인트색, min-width를 줘 자릿수 변화에 레이아웃이 떨리지 않게 한다.
  • 아래 두 줄: "오늘이 n시간 nn분 남았어요"(강조 포인트색) / "하루의 n%가 지나갔어요"(보조색). 1초마다 갱신.

5-2. 하루 고리 (DayRing)

  • 84px 원. 활동당 하나씩 4개의 호(arc)로 분절 — 각 호는 자기 구간의 78%를 채우고 사이가 끊겨 있어 "조각난 원"으로 읽힌다. 완료 호는 포인트색, 미완료는 #E9E1CF. 중앙에 n/4.
  • 의도: 덜 닫힌 원이 항상 보이게 해 완성 욕구를 자극한다. 4개가 모두 닫히는 순간이 하루의 보상이므로, 완료 시 호가 채워지는 트랜지션(0.3s)을 생략하지 말 것.

5-3. 오늘 흐름 타임라인

  • 가로축 06:00–24:00. 위치 함수 px(h) = (clamp(h,6,24) − 6) / 18 × 100%.
  • 축은 9px 높이 트랙(#EEE7D9). 경과 구간은 포인트색 계열 대각 스트라이프가 채우고 계속 흐른다(7-2).
  • "지금" 마커: 상단 pill(포인트색 배경, 지금 HH:MM) + 세로선 + 축 위의 점. 세로선은 축에서 끝난다 — 아래 활동 라벨 영역(축 기준 +21px 아래)과 절대 겹치지 않는다.
  • 활동 4개는 보통 수행 시각 위치에 고리 마크 + 이름. 완료된 것은 회색 처리 + 아래 07:12 · 41분 메타. due 활동은 이름이 포인트색.
  • 시간 눈금 06·09·12·15·18·21·24, 양 끝은 잘리지 않게 끝점 정렬.
  • 영역 전체 pointer-events: none.

5-4. 활동 행

  • 그리드: 18px(마크) · 76px(이름) · 1fr(문장 2줄) · auto(CTA) · 14px(화살표), 간격 16px, 패딩 18px 22px.
  • 마크는 76% 호의 "열린 고리". 완료 시 닫힌 원 + 체크. due 행의 고리는 포인트색으로 7초/회전.
  • 1행(재개 지점): 구체 명사 + 굵은 수치. 예: 『물고기는 존재하지 않는다』 132 / 264쪽. 2행(보조 사실): 보조색 12.5px.
  • 행 전체가 펼침 토글 버튼(aria-expanded). 호버 시 배경 #FCFAF5.

5-5. CTA 버튼

  • 전 행 동일 폭 168px, pill. 좌측 26px 원형 아이콘 캡슐(활동별 아이콘) + 중앙 정렬 라벨 + 우측 ↗.
  • 기본: 흰 배경 + #E6DCC9 테두리. 호버: 포인트색 채움(아이콘 캡슐은 반투명 백색). due 행: 항상 채워진 상태.
  • 라벨은 데이터의 cta 필드 그대로: "이어 읽기" / "이어 쓰기" / "오늘 분량 시작" / "운동 기록 열기"(완료 후 "오늘 기록 보기").
  • 클릭 시 해당 앱으로 이동(딥링크는 구현 시 연결). 행 펼침이 함께 토글되지 않도록 이벤트 전파를 막는다.

5-6. 펼침 영역

  • 2열 그리드: 좌측 월 캘린더(고정폭), 우측 기록 3종. 하단 풀폭으로 beat 라인.
  • 월 캘린더 히트맵: 요일 헤더(월~일) + 이번 달 전체. 셀 19×15px, 미래 날짜는 점선 테두리 빈 셀, 오늘은 포인트색 외곽선. 셀 title로 날짜·수치 툴팁. 설명 캡션은 넣지 않는다(과거 피드백으로 제거됨).
  • 기록 3종: 라벨(11.5px) / 값(24px 800) / 보조(12px). 구성은 활동별로 다르다 — 8절 표 참조.
  • beat 라인: 옅은 포인트색 배경 박스. "오늘의 행동 → 가장 가까운 기록 경신"을 잇는 한 문장. 우측에 [전체 통계] 텍스트 링크.

5-7. 전체 통계

  • 2×2 카드 그리드. 카드: 아이콘+이름+연간 요약(우측) / 8주 막대(이번 주만 포인트색, 0인 주는 바닥선만) / 축 라벨 "8주 전·이번 주" / 기록 3종 한 줄.
  • 메인과 같은 화면 영역을 교체하는 방식(라우팅 불필요). ESC 키 지원.

9카피 규칙

이 화면의 모든 문장이 그대로 출시 문구가 된다. 규칙:

  1. 사용자에게 말 거는 문장은 해요체. 라벨·캡션(최장 연속, 하루 최고 등)만 명사형.
  2. 번역투 금지. "열려 있는 일", "고리를 닫는다", "작업이 닫힌다" 같은 영어 직역 표현 사용 불가. 시각 요소로서의 고리(링)는 유지하되 말로 풀어 쓰지 않는다.
  3. 반말 종결 금지. "남았다 / 썼다 / 비었다 / 멈춰 있다" → 전부 해요체로.
  4. 빈 격려·추상 평가 금지. "잘하고 있어요", "그날 많이 했어요" 불가. 구체값으로만 말한다.
  5. 죄책감 어법 금지. 공백은 사실로만: "마지막으로 쓴 날은 6월 4일이에요". 복귀는 문턱을 낮춰서: "오늘 10분이면 다시 시작할 수 있어요".
