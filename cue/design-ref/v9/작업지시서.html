1설계 원칙 (정보구조 통일)

  1. 네 카드가 같은 골격으로 읽힌다. 펼침의 기록 3종을 직전(최근 한 일) → 이번 주(근접목표) → 추세(이번 달/진척)의 동일한 역할로 정렬한다. 라벨·타이포·진행막대·보조줄이 카드마다 같은 자리에 온다.
  2. 시간 단위는 일 → 주 → 월. 연간 누적은 카드에서 빼고 전체 통계로 보낸다.
  3. 직전 환기(이어보기)를 슬롯 1에. “끝낸 누적”이 아니라 “하다 만 것”을 보여 재개를 유도한다(8절 근거).
  4. 근접목표를 슬롯 2에. “이번 주 N / 목표 M”처럼 가까운 목표를 현재/목표 한 쌍으로 보인다.
  5. 색은 한 곳에만. 포인트색(#D2602F)은 시간·지금 할 일·경신 가능 지점에만. 한 화면에서 세 군데 이상 동시 강조 금지.
  6. 빈 격려·죄책감 어법 금지. 모든 문장은 DB에서 온 구체값. 공백은 사실로, 복귀는 문턱을 낮춰서(5절).

2-2. 펼침 (통일 4행 정렬)

좌측 이번 달 캘린더 히트맵(유지) + 우측 기록 3종. 기록 3종은 라벨 · 값 · 진행막대 · 보조줄 4행을 grid subgrid로 묶어, 칸이 달라도 네 줄이 같은 baseline에 정렬되게 한다(과거: 가운데 칸 막대 때문에 보조줄이 어긋났음 → 해결).

슬롯 1 · 직전최근 한 일 (직전 읽기 분 / 직전 글 매수 / 직전 발화 문장 / 직전 운동 부위)
슬롯 2 · 이번 주현재 / 목표 (예: 3 / 5일) + 진행막대. 근접목표
슬롯 3 · 추세이번 달 또는 진척, 이전 대비 (예: 14회 · 지난달 12회)
beat“오늘 [최소 행동]이면 [가까운 결과] — [기준]” 한 줄

4전체 통계

카드에서 뺀 연간 누적·최장 기록을 여기로 모은다(자부심·회고). 앱별 카드: 아이콘+이름+연간 요약 / 올해 페이스(raw 누적 대신 목표 대비) / 8주 막대(주별 활동 일수=빈도, 이번 주만 포인트색) / 기록 3종.

  • 페이스 예: 운동 “올해 평균 주 3.2회 · 주 4일 목표”. 독서·글쓰기·어학은 “평균 주 N · 제안 주 M”.
  • 기록 3종(통계): 독서=최장 연속·올해 읽은 책·하루 최고 / 글쓰기=올해 편수·올해 매수·편당 평균 / 어학=올해 발화·익힌 문장·최장 연속 / 운동=올해 횟수·최고 주 연속·하루 최고.
  • 닫기 ✕ 또는 ESC.

5카피 규칙

정본(cue/design-ref/v8/작업지시서.html §9) 준수 + 사용자 선호:

  1. 사용자에게 말하는 문장은 해요체. 라벨·캡션(직전 읽기·이번 주·하루 최고 등)만 명사형.
  2. 빈 격려·추상 평가 금지 — “잘하고 있어요”, “많이 했어요” 불가. 구체값만.
  3. 죄책감 어법 금지 — 공백은 사실로(“마지막으로 쓴 날은 6월 4일이에요”), 복귀는 문턱 낮춰서(“오늘 10분이면 다시 시작할 수 있어요”).
  4. 번역투·반말 종결 금지.
  5. 은유·편집적 카피 지양(사용자 선호) — “「제목」이 다시 자라요” 류 금지, 데이터 사실 위주.
  6. beat = “오늘 [최소 행동]이면 [가까운 결과] — [기준 기록]”.

정렬 (필수)

색 절제 규칙

  • ★ 신기록 배지: 운동 직전 세션에 PR이 있을 때만 포인트색(강한 동기 신호라 허용).

9구현 체크리스트 · 미결정

체크리스트

  1. copy.js: 연간 누적·최장연속 대표화 제거, 슬롯 1·2·3을 직전/이번 주/추세로 재작성(5절 문체 전수).
  2. adapter.js: 복습 대기 수(study_review_queue), 부위 2개(session.tags)·PR 개수, 이번 달/지난달·지난주 비교값, 페이스 산출 추가.
  3. AppRow.jsx: 기록 4행 subgrid 렌더 + 진행막대(다음 칸 1개 포인트색) + 제안/목표 칩 + ★신기록 배지.
  4. StatsView.jsx: 페이스 줄 + 8주 빈도 + 통계용 기록 3종(누적·최장 이전).
  5. 발음 점수 제거 확인. 글쓰기 ‘가짜 제목’ 미사용 확인.
  6. 카피 전수 검사(해요체·죄책감 어법·번역투). 정렬 QA(칸 간 보조줄 baseline 일치).
