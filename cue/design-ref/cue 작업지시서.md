# cue — 작업지시서 (로컬 Claude / Claude Code 핸드오프)

> "미루는 4가지(어학·운동·글쓰기·독서)를 **시작하게 만드는** 행동 트리거 대시보드."
> 보조 모니터 상시 표시 + 폰. **보면 들어가게(launch) 되는 화면.**
> 이 문서 + 동봉된 시안 파일로 실데이터 연동 구현을 진행한다.

---

## 0. 동봉 파일 (이 시안이 곧 스펙)

| 파일 | 용도 |
|---|---|
| **`cue.html`** | 오프라인 단일본(폰트 내장). 그대로 열면 동작하는 **완성 시안**. 디자인·인터랙션 기준. |
| `런처.html` | 편집용 진입점(아래 3개 스크립트 로드) |
| `data-l.jsx` | **데이터 모델**(습관 정의·수치·상태·헬퍼). 실연동 시 여기를 교체 |
| `app-l.jsx` | UI/상호작용(헤더·도어카드·오늘흐름·기록·전체통계) |
| `tweaks-panel.jsx` | Tweaks 패널(런타임 조절) |

구현 시 **시안의 픽셀/톤/모션을 기준**으로 삼고, 목업 데이터만 실데이터로 바꾼다. 새 디자인을 발명하지 말 것.

---

## 1. 목적과 맥락

- **단일 사용자**, 데스크톱 보조 모니터에 **상시** 띄워둠("보이면 한다") + 폰 반응형.
- 차분하고(주작업 방해 X) **한눈에 상태가 읽혀야** 함(glanceable).
- 각 카드는 "체크 항목"이 아니라 **해당 앱으로 들어가는 문(door)**. 탭 → 그 앱 실행.
- 완료는 런처에서 찍는 게 아니라 **앱에서 한 결과(DB)가 되비치는 것**.

근거(행동과학): Fogg B=MAP(동기=스트릭 / 능력=한 번 탭 / 자극=오늘 할 일), 습관 루프(cue→행동→보상), 목표 구배, 상태 적응, 손실 회피(끊기 싫은 스트릭).

## 2. 디자인 시스템 (leftjap/apps · DESIGN.md 준수)

**원칙:** 순백 배경 고정 · 따뜻한 웜그레이 모노톤 · **색은 위계용으로만** · **액센트(Crail)는 점 단위로만, 큰 면 색 채움 금지** · **깊이는 색이 아니라 그림자로** · Light only · 이모지 없음.

### 컬러 토큰
```css
--paper:#ffffff;
--ink-1:#1d1b18; --ink-2:#46423b; --ink-3:#6e6962; --ink-4:#a39e95;   /* 잉크 4단 */
--line:#e8e6e2; --line-soft:#f1efec;
--sunken:oklch(97.6% 0.006 60);                                       /* 완료/가라앉음 면 */
/* 히트맵 농담 = 웜그레이(양). 캐러멜/컬러 금지 */
--g1:oklch(87% 0.004 60); --g2:oklch(71% 0.005 60); --g3:oklch(49% 0.006 60);
/* 액센트 — 점 단위만 */
--crail:#d97757; --crail-deep:#b3502f; --crail-soft:#f0c9ba; --crail-wash:#faeae2;
/* (DESIGN.md 2차 액센트 Cloudy #6a9bcc 는 현재 미사용 — 필요 시 점단위로만) */
```
**Crail 허용 위치(점):** 오늘 칸 링 · "다음" 표식 · 라이브 점 · 완료 체크 · CTA 화살표 · 워드마크 점. **그 외 큰 면에 Crail 금지.**

### 타이포
- 본문/한글: **Pretendard**
- 숫자·메타(날짜/시간/스트릭/수치): **Spline Sans Mono** (★ JetBrains Mono는 0 가운데 점이 박혀 오독되므로 **쓰지 말 것**. Spline Sans Mono는 0이 깨끗함)
- 스케일: 스트릭 숫자 = 카드의 hero(34~42px). 라벨/메타 10~13px. 본문 문장 23~33px.

### 깊이
- 흰 위 흰 카드를 **그림자로 띄움**(float). 완료 카드는 **sunken + inset 그림자**로 가라앉힘.
- 라운드: 카드 16~20px, 모달 22px.

## 3. 화면 구조 (위 → 아래)

대시보드 원칙: **실행성 높은 것 위, 과거 기록 아래.**

### 3.1 헤더(히어로)
- 좌상단 **워드마크 `cue`**(소문자 700) + Crail 점 + `오늘 YYYY.MM.DD 요일`(mono).
- **오늘의 문장**: 사용자 codex(운영 규칙서)에서 매일 바뀌는 **행동지향 한 줄**(날짜 기반 결정론적). 핵심 구절에 Crail 밑줄. 새로고침 버튼으로 다른 문장. → "감상용 명언"이 아니라 **바로 아래 행동의 출발점**.
- 우상단 **오늘 N/4** + 4점(완료=Crail). 4개 다 완료 시 "오늘 다 했어요 ✓"(작은 팝 보상).

### 3.2 행동 zone — 도어 카드 4개 (시간순 정렬: 아침→밤)
순서: **글쓰기 → 운동 → 어학 → 독서** (문·오늘흐름·기록 **모두 같은 순서**로 일관 — 습관 스태킹).

각 카드:
- 상단: 이름(한글) + 영문 mono(TODAY/GYM/STUDY/BOOK). **아이콘/아바타 없음.**
- 중앙: **스트릭 큰 숫자**(손실 회피) + 단위.
- cue 한 줄: **오늘 한 양**(예: "오늘 2.1매") / 미실행 시 시작 미끼("복습 8개 대기").
- 하단: **문(열기 →)** — 탭 시 해당 앱 URL 실행.
- 상태별 모습(상태 적응):
  - **미실행**: 흰 카드, 떠 있음(float). "열기/쓰기/읽기 →".
  - **진행(운동만 라이브)**: Crail 라이브 점 + "운동 중 12:18"(경과). 동선엔 "지금".
  - **완료**: **sunken 회색 + 그림자**(색 채움 X) + "오늘 완료" Crail 체크. "다시 열기 →".
- **다음 행동 신호**: 지금 이후 첫 미실행 카드에 **"다음" 태그 + 열기 화살표 은은한 펄스**(시선 유도, Hick's law).

### 3.3 오늘 흐름 (DB 기준 타임라인)
- 가로 시간축 + **"지금 HH:MM"** 마커 + 경과선(Crail-soft).
- **한 건** = DB 기록 시각(글쓰기 06:40). **진행** = "지금". **안 한 건** = **"마지막 ○○"**(직전 세션 시각, 예 "마지막 어제 20:14") — 하지 않은 건 직전 실행을 보여줌.
- 우상단: "오늘 아직 — {미실행 이름들}".
- ※ "동선/정거장" 같은 **스케줄 암시 표현 금지**(실제 스케줄 아님).

### 3.4 그간의 기록 (최근 4주 · 글랜서블)
- 4행(습관별) × 28일 **히트맵**. **칸 농담 = 그날 한 "양"**(웜그레이), 빈칸=안 함(판정 아님), 오늘=Crail 링. 주말 살짝 음영.
- 범례: 안 함 / 적게→많이(그레이 그라데이션) / 오늘 / "칸 진하기 = 그날 한 양(운동 분·어학 문장·글쓰기 매·독서 분)".
- 각 행 우측: **풀 라벨** "연속 N일"(운동은 "이번주 N회") — 0 이면 숫자 dim(ink-4). (2026-06-10: 축 "오늘" 라벨과의 혼동 제거)
- 요약 수치(2026-06-10 개정): **이번주 활동(N/7일)**·**이번주 원고(매)** — 둘 다 월~오늘 기준 — ·**N주 활동률(%)**·**최장 연속(일·최장 습관명 병기)**.
  (구: 최장 연속·활동률·이번주 원고(rolling 7일)·N주 활동(회). "이번주" 정의를 운동 회수와 동일하게 월~오늘로 통일)
- 셀 hover = "M.DD (요일) · N단위" 툴팁.
- **"전체 통계 →"** 버튼 → 모달(아래).

### 3.5 전체 통계 (모달)
- 인-컨텍스트 모달(화면 안 떠남). backdrop = `oklch(22% 0.008 60 / 0.32)` + blur. Esc/바깥클릭 닫힘.
- 습관별 **12주 추세 막대(그레이, 현재 주 Crail 표식)** + 현재/최장/주평균.
- 4주 초과 깊은 통계는 여기로 분리. 더 커지면 전용 화면으로 승격.

## 4. 데이터 모델 (★ 실연동 핵심)

각 습관 = **연속 수치 지표**. 데몬이 각 앱/서버를 체크해 동기화한다.

| 습관 | id | 지표(unit) | 데이터 출처(데몬) |
|---|---|---|---|
| 글쓰기 | today | **원고지 매수(매, 200자=1매)** | Today 앱 DB (오늘 작성 글자수→매수) |
| 운동 | gym | **시간(분)** 또는 총 볼륨 | iPhone 전용 앱 DB (세션 시간/볼륨). **데스크톱에선 실행 불가 → "iPhone 전용" 표기** |
| 어학 | study | **문장 수**(학습+복습 발화) | Study 앱 DB |
| 독서 | book | **독서 시간(분)** | 로컬 데몬이 **밀리의서재** 독서 시간 측정 |

각 습관이 제공해야 하는 값:
- `hist`: 최근 27일 **일별 수치 배열**(0=안 함).
- `today`: 오늘 누적 수치(0이면 미실행).
- `streak`: 연속 일수(수치>0). 운동은 daily streak 대신 **이번주 회수**.
- `lastSession`: 오늘 미실행 시 **직전 세션 시각**(예 "어제 20:14").
- `at`: 오늘 한 경우 **DB 기록 시각**(오늘 흐름 위치/라벨용).
- `url`: 실행 주소. 운동은 `null`(iPhone 전용).
  - 현재 시안 URL: `https://leftjap.github.io/apps/study|today|book/`.

**히트맵 농담 단계**: `level(v,max)= v<=0?없음 : v<0.34*max?g1 : v<0.7*max?g2 : g3`. (max는 습관별 기준치: 글쓰기 3.4매 / 운동 60분 / 어학 46문장 / 독서 50분 — 실데이터 분포로 보정)

→ 구현 시 `data-l.jsx`의 목업 배열을 **데몬/DB fetch 결과로 교체**하면 UI는 그대로 동작한다.

## 5. 인터랙션

- **카드 탭 = 앱 실행**(`window.open(url)` 또는 OS 딥링크). 운동은 실행 대신 "iPhone 전용".
- **데모 모드 토글**(Tweaks): ON이면 탭으로 상태 순환(미실행→진행→완료) 미리보기, OFF면 실제 실행. 실연동 후 기본 OFF.
- 완료 보상 모션: 체크 그려짐 + 카드 가라앉음 + 상단 tally 갱신. **과한 애니 금지**(상시표시).
- `prefers-reduced-motion` 존중(모션 제거).

## 7. 반응형 / 접근성

- 데스크톱(보조 모니터) 4열 → 태블릿 2열 → 모바일 1열.
- 터치 타겟 ≥ 44px. 색만으로 의미 전달 금지(라벨 병기).
- 도어카드 `role="button"` + aria-label(상태 포함). 모달 Esc 닫힘.
