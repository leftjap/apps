## 1. 배경 — 기존 '오늘 흐름'(DayRibbon)의 문제

1. **좌표 충돌**: 완료 습관(실제 DB 시각)과 미실행 습관(고정 대표 시각 `slot.pos`)이 **같은 한 줄**에 섞여, 시각이 가까우면 라벨이 그대로 겹침. 겹침 처리 코드 부재.
2. **의미 구분 약함**: '오늘 한 기록'과 '직전 기록(마지막 어제 20:14)'이 같은 모양의 점이라 글랜스에서 구분 불가.
3. **넛지 부재**: "지금" 마커가 9px 가는 선 하나 — 시간 압박(B=MAP의 자극)을 전달하지 못함.

## 2. 새 구조 — 핵심 원칙

- **시간이 화면의 bold element**: 대형 라이브 시계(초 단위) + "오늘이 N시간 N분 남았다"(손실 프레임). 잔소리 문구 금지 — 시간 자체가 말하게 한다.
- **2레인 분리**: 타임라인 **선 위 = 오늘 실제 기록**(DB 시각, 채운 점) / **선 아래 = 미실행 고스트**(평소 시간대, 점선 점). 직전 기록은 고스트의 보조 라벨로만. → 좌표·의미 충돌의 구조적 해소.
- 배치: 헤더 바로 아래(도어 위). 실행성 높은 것 위 원칙 유지 — 시간 밴드가 도어로 들어가게 만드는 자극이므로 최상단.

## 3. A안 — 시간 밴드 (기본 채택)

```
┌ 오늘 흐름 ──────────────────────── 오늘 아직 운동 · 어학 · 독서 ┐
│  16:15₄₀          글쓰기            [지금 16:15]                │
│                    06:40 · 2.1매      │                         │
│  오늘이 7시간      ●━━━━━━━━━◌━━━━━━●─────◌──────◌────         │
│  44분 남았다           운동[다음]        어학      독서          │
│  하루의 68% 경과       보통 13:50       보통 20:00 보통 22:30    │
│                        마지막 그제13:20  마지막…    마지막…      │
│                   06   09   12   15   18   21   24             │
└─────────────────────────────────────────────────────────────────┘
```

### 3.1 시계 블록 (좌, 196–232px)
- `HH:MM` Lekton 700, clamp(42–58px). 콜론은 좌우 마진 −0.075em(사이드베어링 보정) + **2s 점멸**(steps(1), opacity 1 → 1−모션×0.62).
- 초: 0.42em, Lekton 400, `--crail-deep`, 매초 갱신. Tweaks로 숨김 가능.
- 미실행 있을 때: "오늘이 **N시간 N분** 남았다" (수치 mono 700 `--crail-deep` 16px). 다 했을 때: "**오늘 다 했어요** — 남은 시간은 덤".
- 보조: "하루의 N% 경과" (micro mono, `--ink-4`).
- **단계적 긴급도**: 미실행 > 0 **그리고** 잔여 ≤ 240분(20시 이후)이면 수치에 `breathe` 펄스(2.4s, opacity 1 → 1−모션×0.45).

### 3.2 타임라인 (우)
- 창: 기본 06:00–24:00 (Tweaks 0/3/6/9시). `pos = (min − start) / (1440 − start×60) × 100`, 점은 1.5–98.5% 클램프.
- 축: 2px `--line`, 축 y = 88px (컨테이너 182px).
- **경과선**: 4px, `--crail-wash → --crail-soft` 그라데이션 + 흐르는 하이라이트(`sweep` 3.4s, 폭 34%, 강도 = 모션×70%). 이음새 보이는 200% 배경 이동 방식 금지.
- **지금 마커**: 2px `--crail` 수직선(top 6 → bottom 22) + 축 위 12px 헤드(`nowpulse` 2.2s, 퍼짐 = 모션×11px) + 상단 필 라벨 "지금 HH:MM"(흰 글자/`--crail` 배경/r-6).
- **점 (전부 축 위 한 줄)**: 오늘 기록 = 13px 채운 `--crail` + `--crail-wash` 링 / 진행(운동 라이브) = `--crail-wash` 채움 + `--crail` 보더 + 펄스 / 미실행 고스트 = 12px 흰 바탕 + **2px dashed** `--ink-4`, **밀린 것(평소 시각 < 지금)은 dashed `--crail`**.
- **캡션 위 레인**(기록): 이름(12px 600) / 시각(mono 10px `--crail-deep` 700) / 양(mono 9px `--ink-4`).
- **캡션 아래 레인**(미실행): 이름(`--ink-3`, 밀린 것은 `--ink-1`) + [다음] 태그 / "보통 HH:MM"(mono 10px) / "마지막 어제 20:14"(mono 9px, 밀린 것은 `--crail-deep`).
- 캡션 x는 4–94%(아래 레인 93%) 클램프 — 가장자리 잘림 방지. 점은 실좌표 유지.

### 3.3 라벨 충돌 회피 (`staggerLane`)
레인별로 pos 오름차순 정렬 후, 직전 라벨과 **19%p 미만**이면 다음 줄로 (최대 3줄). 줄 오프셋: 위 레인 −30px/줄, 아래 레인 +34px/줄. 결정론적 — 같은 데이터면 항상 같은 배치.

### 3.4 "다음" 선정 (`nextOf`)
미실행 중 **밀린 것(평소 시각 ≤ 지금) 우선, 그중 가장 이른 것** → 없으면 가장 가까운 예정. 도어 카드의 [다음] 태그·펄스와 동일 소스 사용 (한 곳에서 계산해 공유).

## 4. B안 — 카운트다운 (대안, Tweaks 전환)

거대 시계(clamp 56–92px, 동일 콜론/초 규칙) + **시간 블록 소진 바**(시작시~24시, 시간당 1칸 14px: 지난 칸 `--g1` 채움 / 현재 칸 부분 채움 `--crail-soft` + 우측 에지 1s 점멸 / 남은 칸 outline) + 잔여 문구(§3.1과 동일 + 긴급도) + **습관 칩**(평소 시각순): 완료 = sunken + ✓`--crail-deep` + "HH:MM · 양" / 진행 = 라이브 점 / 미실행 = outline + "마지막 …", [다음] = `--crail-soft` 1.5px 보더 + 태그. 칩은 `white-space:nowrap`.

## 5. 데이터 모델 (기존 정본에 추가되는 필드)

| 필드 | 의미 | 산출 |
|---|---|---|
| `usualMin` | 평소 실행 시간대(분) — 고스트 점 위치 | **최근 4주 실행 시각의 중앙값**. 기록 < 3회면 기존 대표 슬롯 폴백 |
| `atMin` | 오늘 DB 기록 시각(분) — 기록 점 위치 | 기존 `at`(`latestTodayTs`)에서 분 단위로 |
| `amount` | 오늘 한 양 라벨 ("2.1매") | 기존 `today` + 단위 |
| `last` | 직전 세션 라벨 ("어제 20:14") | 기존 `lastSessionLabel` 그대로 |

기존 `slot.pos`(고정 대표 시각) 필드는 **폐기** — `usualMin`으로 대체.

## 6. 인터랙션

- **타임라인 캡션·B안 칩 = 문**: 탭 시 해당 앱 실행(도어와 동일, `launchHabit` 재사용). 운동은 iPhone 전용 — 무동작 유지. 데모 모드에선 상태 순환. `<button>` + focus-visible 링 + aria-label(상태 포함).
- 시계는 `role="timer"`. 초 갱신은 1s interval 하나로 통합(시계·타이머·자정 롤오버 공용).
- 데모 시각(Tweaks): 실시간 OFF 시 슬라이더 시각 기준 + 초는 계속 흐름 — 시간대별 상태 검증용. 실연동 후 기본 ON(실시간).

## 7. 모션 규칙 (상시표시 화면 — 절제)

- 전역 `--motion`(0–1, Tweaks 0–100). **0이면 `--anim:paused`로 전부 정지.** `prefers-reduced-motion: reduce`도 동일.
- 상시 모션은 4종뿐: 콜론 점멸 / 경과선 sweep / 지금 헤드 펄스 / (조건부) 긴급 breathe. 그 외 모션 추가 금지.
- 모든 keyframes는 `animation-play-state:var(--anim, running)` 패턴 준수.

## 8. 하지 말 것 (기존 정본 + 추가)

- 직전 기록과 오늘 기록을 같은 레인·같은 모양으로 섞기 (이번 개편의 핵심 금지사항).
- 잔여 시간 문구에 훈계 톤("빨리 하세요" 류) — 숫자와 펄스만.
- 경과선에 이음새 보이는 배경 이동 애니메이션.
- JetBrains Mono(0 점 박힘) — mono는 **Lekton** 고정.
- 큰 면 Crail 채움 (지금 마커 필 라벨·점·필스는 점 단위 허용 범위).
