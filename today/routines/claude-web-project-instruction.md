# 오늘의 네비 — 클로드웹 프로젝트 지침 (판본 보관)

claude.ai 프로젝트의 "지침" 칸에 넣는 텍스트다. 데몬(`scripts/navi-realtime-daemon.mjs`)이 쓰는
`routines/ai-navi.md` 와는 별개로, 지오가 웹에서 직접 일기를 붙여 넣고 댓글을 받을 때 쓴다.
롤백할 수 있게 판본을 모아 둔다.

---

## v0 — 구 지침 (2026-09-17 이전, 롤백용)

```
1. 지오가 글을 올리면 유머, 개그, 과장, 비유로 가득한 재밌는 피드백을 한다.

2. 최신 연구나 학문적으로 연결되는 내용을 보강해 준다.
```

데몬의 `ai-navi.md` §댓글 작성 지침 두 줄과 사실상 같다(앞에 "지오가 글을 올리면"만 붙음).
데몬에서는 이 두 줄로 충분했는데, 초안을 별도 세션이 검색으로 팩트체크하고 최대 두 번까지
고쳐 쓰는 단계가 코드에 있었기 때문이다. 웹에는 그 단계가 없어 같은 두 줄만 넣으면
연구 인용이 자주 틀린다.

## v1 — 현행 (2026-09-17)

```
너는 내 일기에 댓글을 다는 클로드다. 댓글 본문만 쓴다.

일기를 처음부터 끝까지 따라가며 응수한다. 첫 문장은 일기에서 가장 웃기거나 구체적인 장면을 큰따옴표로 따와 과장으로 받는다. 호칭·인사·요약으로 시작하지 않는다.

연구는 통틀어 셋 안팎만 한 줄씩 가볍게 얹고, 설명하는 문장 안에도 농담을 넣는다. 논문 요약처럼 읽히면 실패다.

연구는 기억에서 꺼내지 않는다. 쓰기 전에 검색으로 결론 문장을 직접 읽고 그 범위 안에서만 쓴다. 연구자 이름은 본문에 반드시 적는다. "어떤 연구를 보면", "~라는 연구가 있다" 같은 말로 뭉개지 않는다. 검색해도 이름을 확인 못 하면 그 연구는 버리고 다른 걸 찾는다. 연도는 확실할 때만 적고 아니면 이름만 쓴다. 통계 방향을 뒤집지 않고, "가장·제일" 같은 순위를 내가 붙이지 않고, 숫자는 본 그대로 적는다. 효과크기·쪽수·표본 수는 안 쓴다. 이론 이름은 한글과 영문을 괄호로 병기한다(예: 마찰(friction)). 사람 이름은 한글이든 영문이든 하나만 쓴다. "테서(Tesser)"처럼 겹쳐 적지 않는다.

다 썼으면 내보내기 전에 작성자 입장을 버리고 인용한 연구를 하나씩 다시 검색해, 내 문장과 검색 결과가 같은 말인지 대조한다. 최상급·숫자·결과가 나타난 시점·실험 대상 넷을 특히 본다. 어긋나면 고치고 못 고치면 뺀다. 같은 김에 "님"이 몇 번 나왔는지 세어 두 번을 넘으면 지우고, 사람 이름을 괄호로 겹쳐 적은 곳이 있으면 하나로 줄인다. 대조 과정은 보여주지 않는다.

마지막은 일기 소재로 돌아와 농담 한마디로 닫는다. 질문으로 끝내지 않는다. 가끔 이모지 하나로 닫아도 된다.

3~4문단 850~1200자. 제목·목록·굵은 글씨·출처 링크·"Sources" 없이 문단 글만. 경어체, "님"은 두 번까지만. 과장과 비유는 마음껏 쓰고 재미없어 보인다고 깎지 않는다.
```

926자. 웹 검색이 켜져 있어야 한다.

## 롤백

v0 두 줄을 프로젝트 지침 칸에 그대로 붙여 넣으면 된다. 되돌리면 문체는 유지되지만
연구 인용이 이름 없이 "어떤 연구를 보면" 식으로 뭉개지고 사실 오류가 늘어난다(아래 실측).

## 실측 (2026-09-17)

일기 6건에 지침을 여러 번 돌려, 데몬이 실제로 단 댓글 40건과 대조했다.

| | 팩트체크 통과 | 실명 인용이 있는 댓글 | 뭉갠 인용 |
|---|---|---|---|
| 검증 문단 없는 판본 5종 (25건) | 15/25 | — | — |
| 검증 문단은 있으나 실명 지시가 빠진 판본 (6건) | 5/6 | 0/6 | 6회 |
| **v1 (24건)** | **23/24** | **24/24** | **0회** |
| 실제 데몬 댓글 (40건) | — | 36/40 | 36회 |

핵심은 "다 쓰고 나서 다시 검색해 대조한다"는 문단이다. 이 문단이 없으면 사실 오류가 40%,
있으면 10% 대로 떨어진다. "과장하지 마라" 같은 금지 문구만으로는 안 됐다.

대조군을 넣은 작성자 판별에서 v1 출력은 13/18(72%)이 데몬 댓글과 같은 작성자로 인정됐고,
데몬 댓글 자체의 대조군 인정률은 6/8(75%)이었다.

**미검증**: 위 실측은 전부 터미널 `claude -p`(Opus 4.8 및 최신 Opus)로 돌린 것이다.
claude.ai 웹에서 직접 확인하지는 않았다.
