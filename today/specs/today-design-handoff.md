## 0. 빠른 시작 — 라이브 mock 보는 법

핸드오프 작업 시 항상 라이브 mock 띄워서 직접 인터랙션 확인:

```
preview_start name=today-mocks         # port 4700, ~/apps/today/ 정적 서빙
→ http://localhost:4700/mocks/today-mac.html
```

- 단일 파일: `~/apps/today/mocks/today-mac.html` (~6,200 줄, HTML+CSS+JS 전부 인라인)
- 이게 디자인 원본. 실 앱(`src/`)은 이 mock 을 `?raw` import 해서 `<script>` 만 분리 실행하는 얇은 SPA 래퍼.
- 즉 **디자인 변경은 mocks/today-mac.html 한 파일에서 끝남**. src/ 건드리지 않아도 됨.

뷰포트 권장: 1440×900 (데스크톱 1차 타깃, 모바일/태블릿은 보조).

## 3. 사이드바 (Sidebar)

### 3.1 sb__top

| 요소 | 내용 |
|---|---|
| `.sb__brand` | "Today" 워드마크 |
| 🔍 검색 (⌘K) | spotlight 모달 오픈 (`openSpotlight()`) |
| 🔔 알림 | `.sb__icon-btn--has-alert` — 빨간 점 + 카운트 |
| ⊟ 토글 | 사이드바 240px ↔ 60px |

### 3.2 카테고리 nav (`.sb__group`)

5개 항목 — 각각 의미 아이콘 + 라벨:
1. **오늘의 네비** — 항해 컴퍼스 (방향/오늘의 항로)
2. **단편** — 짧은 글 (한 페이지)
3. **블로그** — RSS / 발행
4. **메모** — 메모지 (사각형 + 가로줄)
5. **가계부** — 동전 (지출 누적, 우측에 월누적 금액 표시 `1,284,500 원`)

active 항목: 배경 강조 + 아이콘 색 강조.

### 3.3 sb__group--recents

active 카테고리의 최근 항목 동적 갱신. 라벨이 카테고리 이름으로 바뀜 (예: "오늘의 네비" / "가계부").

- **글쓰기 카테고리**: 글 제목 + 우측 메타(`1년 전`, `소연` 공유 등). 최대 30건 컷 — `entries.js` `rows.slice(0, 30)`.
- **가계부**: `상호명 — 메모` + 우측 금액 (ink-3 톤, 강조 X)
- **빈 상태**: 항목 0개면 라벨까지 숨김 또는 placeholder.
- **자체 스크롤 (scrollbar 시각 0)** — `overflow-y: auto` + `scrollbar-width: none`. 30건 안에서 스크롤. 사이드바 외형 변하지 않음.

#### 3.3.1 전체 보기 진입점 (글쓰기 4종 한정)

리센츠 리스트 직하단에 "전체 보기 →" inline 진입점. 클릭 시 메인 영역이 §5.0 의 전체 글 목록 뷰로 전환.

- 위치: `.sb__group--recents` 내부 마지막 child — 리스트 마지막 항목 다음 inline 배치 (sticky 폐기).
- 마크업: `<button class="sb__recents-more" type="button">전체 보기 →</button>` — SPA 레이어가 mocks 출력 갱신 시 함께 주입.
- 스타일 (DESIGN.md ghost ink-3 톤 — 액센트 점 단위 원칙 준수):
  - `color: var(--ink-3)`, `font-size: 12px`, `font-weight: 500`, `line-height: 1.5`
  - hover: 배경 `var(--hover-bg)` + `color: var(--ink-1)` (다른 nav 항목과 일관)
  - **우측 정렬** (`justify-content: flex-end`) — 보조 진입점 위계
  - 배경 transparent, border 0, border-radius 8px
  - **sticky 폐기** — 리스트와 한 묶음으로 자연스럽게 스크롤됨. 가이드 "One bold element + restraint" 준수 (사이드바 액센트 이미 active 카테고리·알림 dot·아바타 3곳 사용 중 — orange 추가 시 과다).
- 표시 조건: 글쓰기 4종(navi/fiction/blog/memo) 한정. 가계부는 비표시 (가계부는 §5.5 mini-tabs 로 별도 처리).
- 빈 상태(글 0건): 라벨·리스트와 함께 진입점도 숨김.
- 30건 미만일 때도 표시 (일관성). 1차 구현 카운트 미표시 — 단순 "전체 보기".
- 카테고리 전환 시 활성 카테고리 기준으로 갱신.

### 3.4 sb__footer

좌하단 사용자 카드 → 클릭 시 popover 메뉴 (프로필 / 휴지통 / —— / 로그아웃).

## 5. 카테고리별 페이지

### 5.0 메인 영역 모드 — 편집 ↔ 전체 목록 (글쓰기 4종 공통)

글쓰기 4종(navi/fiction/blog/memo)은 메인 영역에 두 가지 모드를 가진다.

| 모드 | 컨테이너 | 진입 |
|---|---|---|
| **편집 뷰 (default)** | `<article class="doc">` | 카테고리 진입 시 기본, 리센츠 항목 클릭, 새 글 생성 |
| **전체 목록 뷰** | `<div class="doc-list">` | §3.3.1 "전체 보기 →" 클릭 |

#### 5.0.1 컨테이너 구조

`#mainView` 내부에서 둘 중 하나만 마운트. `#mainView` 의 `flex: 1` + `overflow-y: auto` 룰을 양쪽 모드 공통 사용 (별도 컨테이너 신설 안 함).

#### 5.0.2 전체 목록 뷰 — 레이아웃

- 폭: **720px 단일 칼럼 중앙 정렬** (`.doc` 와 동일).
- 상단 breadcrumb: `{카테고리명} / 전체 글 ({N})`
  - 스타일: `.doc__meta` 톤 차용 — `font-mono` 11px, `var(--ink-3)`, 하단 1px `var(--line-soft)` hairline, `margin-bottom: 26px`.
  - 카테고리명 부분 클릭 가능 → 편집 뷰 복귀.
  - Esc 키도 편집 뷰 복귀 (1차).
  - X 버튼 1차 미도입.
- 항목 마크업: `.spotlight-item` 패턴 그대로 재사용 ([mocks 2729-2779]).
  - 좌측 아이콘: 사이드바 카테고리 아이콘 동일 (16x16).
  - 중앙 stack: title + meta(`YYYY-MM-DD · {N}자`).
  - navi 한정 우측: `<span class="recent-share">{이름}</span>` — 파트너 글일 때만.
- 행 간 1px `var(--line-soft)` hairline.
- 호버 `var(--hover-bg)`.
- 클릭 시 해당 글의 편집 뷰로 전환.

#### 5.0.3 데이터 쿼리

- **navi**: 기존 `entries.js` `fetchEntriesForCategory('navi')` 로직 재사용 — `navi` + `soyoun_navi` 합집합, `owner_id == 본인 || is_shared` 필터, `created_at desc` 정렬.
- **fiction / blog / memo**: `Queries.listEntries(kind)` — `[kind+updated_at]` desc.
- 모든 분기에서 `deleted_at` 자동 제외 (`listEntries` 기본 동작).
- **30건 컷 제거** — 전체 행 반환.
- 정렬 옵션 토글 1차 미도입.

#### 5.0.4 모드 state 와 전환 동작

- 메모리 state: `_activeMainView = 'article' | 'list'` (모듈 스코프, `entries.js`).
- URL 미반영 (가계부 mini-tabs 와 동일 원칙). 새로고침 시 `'article'` 복귀.
- **카테고리 전환 시 자동 `'article'` 복귀** — 전체 목록 상태가 카테고리에 종속.
- **새 글 생성("+" 버튼) 시 자동 `'article'` 복귀** — 새 글 마운트 + 다음 진입 시 리스트 갱신.
- expense 카테고리는 영향 없음 — 기존 mini-tabs 그대로.

#### 5.0.5 chip 필터 표시 분기

- **navi / soyoun_navi 한정**: `전체 / 공유된 글 / 소연이 공유한 글` 3종 chip 노출. 파트너 공유 메타포는 navi 카테고리 전용.
- **fiction / blog / memo**: chips 영역 통째로 미노출 (단일 chip 만 있어 의미 없음). stats + 리스트만.

#### 5.0.6 파트너 글 read-only (navi 한정)

- 파트너(`row.owner_id !== 본인`) 글 진입 시 편집 뷰는 **읽기 전용**:
  - `<h1 class="doc__h1">` / `<div class="doc__body">` 의 `contenteditable` 속성 제거.
  - `article.dataset.readOnly = '1'` 표식 — saveArticle 가 저장 자체 차단 (devtools 우회 방어).
  - 메타: `{이름} 작성 · 읽기 전용 · {기존 단어/시간}` 형태.
  - top-actions 의 `.share` 토글은 `share--readonly` 클래스로 숨김 (작성자만 공유 결정).
  - caret-color: transparent (시각 피드백).
- 댓글 영역은 정상 노출 (공유된 글에 한해 — 기존 동작 유지).

→ **스샷 6** (상단), **스샷 8** (스크롤 후)

- **누적 카테고리 막대**: 5개월 누적, 카테고리별 가로 막대 + 우측 금액. `+ 5개 더 보기` 토글.
- **누적 브랜드 TOP 10**: 순위·로고·이름·금액 가로 리스트.
