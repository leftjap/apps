# 라이투미 — 시제품 설계 v3 (2026-11-11)

시제품. 이름은 라이투미(지오 결정, 이전 이름 '오늘의 눈치'). 시안은 GitHub Pages 링크로 보여 준다(지오 지시): https://leftjap.github.io/apps/lietome/ . 공개 저장소라 링크를 아는 사람은 누구나 열 수 있다. 제미나이 원본(`raw/`)과 확인용 화면(`tools/shots*`, `tools/*.jpg`)은 `.gitignore` 로 커밋하지 않는다. 쓰지 않는 v2 사진은 `raw/v2-img/` 에 보관.

## 규칙 (라이 투 미형, v3)

- 사건마다 같은 팀 부장·대리·사원에게 부고를 전한다. 사람마다 **평소 얼굴을 먼저** 보고 "부고 전하기"를 누르면, 지오의 말이 나온 뒤 **소식을 들은 직후 얼굴**로 바뀐다.
- 셋 다 비슷하게 슬퍼 보이지만 한 명은 꾸민 슬픔이다(노골적인 표정 대신 비슷하지만 가짜인 표정, 지오 지시). 꾸민 슬픔은 입꼬리만 내리고 **눈썹 안쪽 끝이 올라가지 않는다**. 근거: 에크먼 그룹 "What is Sadness?" — 눈썹 안쪽 끝이 올라가는 것은 슬픔의 가장 믿을 만한 신호이고 일부러 움직이기 어렵다.
- 가짜 놀람은 지속 시간으로 구별한다는 설명뿐이라 정지 사진에는 쓰지 않았다(영상으로 갈 때 후보).
- "누르고 있으면 평소 얼굴"로 비교한 뒤 꾸민 표정의 단서를 **탭해서 지목**. 다른 사람 0점, 꾸민 사람이면 50점에 단서(꾸민 슬픔은 미간)까지 거리에 따라 최대 100점. `src/logic.js` 의 `pinScore`.
- 결과: 사건별 🟢(80+) 🟡(40+) 🔴 와 총점, 연속 기록, 공유 문구.
- 사진: 평소 얼굴은 사람마다 `img/<사람>-base.jpg` 한 장, 소식 직후는 사건마다 `img/<사건>-<사람>.jpg`.
- 지금 사건은 d1(김 과장 부고) 하나. 대리·사원 사진은 앞서 만든 얼굴(박은정, 최민지)을 다시 썼다. d2(박 상무 부고)는 대리·사원의 소식 직후 사진이 없어 DAYS 에서 뺐다.

## 사진 만들기

- 디버그 크롬(9333, 지오 구글 계정 로그인)의 제미나이 웹 **임시 채팅**에서 사람마다 한 채팅을 쓴다. v3 는 ① 평소(무표정) ② "첫 이미지와 같은 사람, 표정만 바꿔"(사건별 소식 직후) 순서다. v2 는 반대 순서(표정 → 무표정)였고 둘 다 얼굴·옷·방이 유지됐다. 도우미는 `tools/gemini-helpers.js`.
- 받아 오기: 캔버스로 그려 데이터 URL 을 `raw/` 에 저장 → `tools/decode.py`(v2 형식) 또는 `tools/decode3.py <사람>`(평소, 사건1, …, 사건2=마지막 장) 이 768px JPG 생성. 채팅이 길어지면 앞쪽 이미지가 DOM 에서 빠질 수 있으니 장마다 바로 받는다.
- 단서 위치: `python3 tools/tells.py <이름…>` 이 평소·답할 때 사진 차이가 가장 큰 곳을 찾아 `tools/tells.json` 과 확인용 `tools/tells-check.jpg` 를 만든다. 확인 후 `cases.js` 의 `tell` 에 넣는다.
- 단서 위치: 표정이 생긴 곳은 `tools/tells.py` 의 차이 계산으로, 꾸민 슬픔처럼 '움직이지 않은 곳'이 단서면 격자를 그려 눈으로 정한다.
- 주의: 2026-11-11 창 4개로 15분에 약 19장 만들었을 때 구글이 reCAPTCHA(비정상 트래픽)를 띄웠다. 사람 확인은 우회하지 않는다. 같은 날 저녁 창 하나로 3장 더 만든 뒤에는 이미지 요청이 빈 응답으로 끝났다(한도로 추정). 하루에 만들 수 있는 양이 적으니 나눠서 만든다.

## 빌드·확인

- `node --test test/*.test.js` (점수·날짜 로직, 오늘 사건의 인원·거짓말 1명·단서·사진 존재)
- `node build.mjs` → `dist/index.html`, `dist/img/*`(오늘 나오는 사건의 사진만)
- `node tools/flow.cjs tools/shots <단서 x> <단서 y>` → 375×760 으로 세 사람에게 부고를 전하고, 평소 얼굴을 누르고, 단서를 탭해 지목하는 전 과정을 찍는다(사건 2가 있으면 일부러 다른 사람 지목).
- 게시: main 에 푸시하면 `.github/workflows/deploy-pages.yml` 의 "Build lietome" 단계가 테스트 → 빌드 후 `/apps/lietome/` 으로 올린다. 테스트가 실패하면 이 앱만 빠지고 다른 앱 배포는 계속된다.
