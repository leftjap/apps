# ~/apps/notes/

앱 코드와 무관한 대화 정리·에세이·사변 기록. 한 파일 = 한 대화(또는 한 주제).

## 규칙

- 파일명: `YYYY-MM-DD-<slug>.md` (날짜는 대화 시작일, slug 는 영문 kebab-case)
- 머리: 제목 + 일시·참여·성격(사실/사변 구분) 세 줄
- **공개 repo** (`leftjap/apps`). 개인정보·자격증명·타인의 비공개 정보·스크린샷 금지. 검증 안 된 사실은 문서 안에 그렇게 표시
- `CLAUDE.md` 에 `@import` 하지 않음. 필요 시 Read 로 직접 읽음 (`lessons/` 와 같은 lazy load)
