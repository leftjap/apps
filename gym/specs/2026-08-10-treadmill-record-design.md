# 트레드밀 기록 재설계 — 5필드 수기 입력·즉시 확정·최근 8회 차트

2026-08-10 승인. 발단: 실기기 보고 — ① 스와이프 완료가 유산소에 안 맞음 ② 콘솔(경사·칼로리·속도)이
종료 3~5초 뒤 꺼져 정보 유실 ③ 직전 러닝 기록이 안 보임. 사용자 워크플로: 러닝 종료 직후 콘솔
사진을 찍어 두고, 사진을 보며 앱에 수기 입력 (OCR 없음 — 7세그먼트 오인식·검수 비용으로 기각).

## 1. 입력 — 5필드, 스와이프 제거, 건드린 것만 기록

- 필드: **시간(분)·거리(km)·속도(km/h)·경사(%)·칼로리(kcal)** — 콘솔 평균값 전사.
  기존 커스텀 키패드 (§6-3-2). 속도·경사·칼로리는 세그 없는 bare 키패드(체중 패턴) + 타이틀.
- **입력 즉시 확정 (구현 확정 의미)**: 키패드 입력 순간 세트가 터치됨(preset false) —
  이 시점부터 종료·마감·종목완료 어느 경로로도 기록 보존이 보장된다(cardioEntered 술어).
  done 플래그는 입력 즉시 세우지 않는다: 즉시 done 이면 블록 완료 판정 → 히어로가 다른
  종목으로 자동 이동해 5필드 입력 흐름이 끊긴다 (heroBlockIdx = 첫 미완료 블록).
  사용자 피드백은 필드값 고스트(ink4)→잉크 전환. 좌 스와이프·완료 칩은 유산소 카드에서 제거.
- **프리셋은 값을 싣지 않는다**: presetSets(fromPrev:)의 유산소 값 카피 제거 — 프리셋에
  값이 남으면 한 필드만 입력해도 나머지 상속값이 기록에 딸려 들어간다(필드 단위 유령 값).
  직전 값 고스트 표시·프리필은 세트가 아니라 이력(recentCardioRuns)에서 온다.
  키패드 프리필 = 현재 입력값 > 직전 러닝 값 — 탭→완료 두 번이 "지난번과 같음" 수용.
- **확정 술어 교정**: "값>0 = 입력됨"(2026-08-02) → "**preset 아님 = 입력됨**".
  프리셋이 직전 값을 상속해 값>0 이므로, 옛 술어는 스와이프 시 completeSet 이 덧붙인
  프리셋(duration·distance 복사)까지 확정해 유령 기록을 만들었다 — 2026-08-06 실데이터로
  규명 (동일값 900s/1.5km 세트 2개: preset:False + preset:True 둘 다 done → 그날 유산소
  30분 이중 집계). finishBlock(isCardio:)·confirmEnteredCardio 동일 교정.

## 2. 카드 레이아웃 — 정보 중요도 3단 (§6-4 대체)

```
┌─────────────────────────────────┐
│ 트레드밀                        │
│  ▁▂▂▄▄▆ 최근 8회 (막대=분)      │  ← 이력: GymTrendChart 기하 재사용, 마지막 막대 강조
│  직전: 15분 · 1.5km · 경사 3.4  │     기록 3회 미만이면 차트 생략, 직전 줄만
│  시간 [15]분      거리 [1.5]km  │  ← 1행 크게: 핵심 (얼마나 달렸나)
│  속도 [6.0]km/h   경사 [3.4]%   │  ← 2행: 강도
│  칼로리 [81]kcal · 페이스 10:00 │  ← 3행: 결과 (§7-3 '강조 안 함' 유지) + 페이스 자동
└─────────────────────────────────┘
```

- 하루 2회 러닝 = 막대 2개 (회 단위 축 — 기간축은 주 3~4회 빈도에서 빈약, 사용자 승인).
- 차트 기하: GymTrendChart 는 viewBox 320×160(2:1) 고정이라 스트립형 미니 차트에 부적합
  (레터박스로 폭 손실) — 비례(slot×0.55)만 계승해 CardioPanel 이 직접 그린다.
  8칸 고정 슬롯·최신이 오른쪽 끝(빈 슬롯 왼쪽)·마지막 막대 crail 강조·lineSoft 베이스라인.
  속도·경사는 콘솔 표기 정합 1dp 고정("6.0"·"3.4"), 기록 3회 미만이면 차트 생략.
- 페이스 = 시간÷거리 자동 (기존 paceText).

## 3. 칼로리 — 입력값 우선 합산

- 세션 총계 = 근력 MET 추정(현행 유지) + **유산소는 입력 kcal 우선, 미입력 시 MET 추정 fallback**.
- 근거 (2026-08-10 검토): 트레드밀 MET 7.0 고정은 조깅 가정 — 실사용(6km/h 걷기·경사 3.4)
  대비 +65% 과대 (앱 ~134 vs 콘솔 81, 체중 72.7kg). 콘솔 값 입력이 이 오차를 제거.
  근력 MET(3.5~5.0)는 표준 범위·추세 일관성 위해 유지.
